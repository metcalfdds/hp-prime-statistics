HP Prime Statistics

Free teaching programs for the HP Prime graphing calculator and HP's free Virtual Calculator, for introductory statistics. If your book or your instructor sent you here, start with the first box.

For students: start here Put your chapter's programs on the Virtual Calculator The HP Prime Loader. Pick your chapter, follow the steps, then start the calculator: the programs are waiting for you, and nothing needs setting up. The page explains each step as you go, in Edge, Chrome or Firefox. Your own data Turn a spreadsheet into a calculator data file The HP Prime Data Loader. Paste columns from Excel, SPSS or a CSV file and download the calculator's own matrix file. The DataLoad program then puts the columns into the calculator's statistics lists. Nothing you paste leaves your computer. Everything else The programs, their guides and the notes, on GitHub All 30 programs as plain text, user's guides, the starter pack, and a long set of notes on how the HP Prime really behaves.

Need the Virtual Calculator? It is a free download for Windows: hpcalc.org's HP Prime page lists it, with Hewlett-Packard as its author. Install it, start it once, and close it again before you use the Loader.
