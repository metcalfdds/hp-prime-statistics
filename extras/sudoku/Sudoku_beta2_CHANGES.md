# Sudoku beta 2: changes, checks and device checklist

*26 November 2026. Program file: `Sudoku_beta2.txt` (1,629 lines, 80,548 characters), built from `Sudoku_beta2_template.txt` by `Sudoku_beta2_build.py`. Verify script: `verify_Sudoku_beta2.py`, with its output beside it. Replaces beta 1 (25 November 2026), which goes to `_superseded`.*

## Why

Roger asked (26 Nov 2026, 00:01) to "compare ours to the other ones and see what you can learn from them and then make ours super duper cool." Beta 1 was a solver only: the puzzle had to be typed into matrix M9 with the matrix editor, the program solved it, and the answer was shown. Three Sudoku programs in the hpcalc.org library were read for ideas, and each one does something that ours did not:

- **Lennart Börjeson's Sudoku editor/solver (2015, PPL)** lets the player choose a square by tapping it, keeps its actions on a menu strip, has an undo list, and can show the digits a square can still take.
- **chromos's Sudoku solver (2024, PPL)** works with the two simplest human steps, the "naked single" (only one digit fits a square) and the "hidden single" (a digit fits in only one square of a row, column or box), and counts how many squares each step filled.
- **HPleak's Sudoku solver (2023, MicroPython)** draws its brute-force search on the screen while it runs.

None of their code is in beta 2, which was written new; the header and the last help page say so in plain words, and name the three programs. What beta 2 adds is the thing none of them does, which is a game a student can play from start to finish, with a hint that explains its reasoning, so the program teaches how a Sudoku is worked out rather than only producing the answer.

## What it does now

- **Four levels of puzzles, each with exactly one answer.** The program carries 24 puzzles of its own (6 at each level), made and graded by `su_gen.py` with the program's own solver: Easy puzzles fall to the only-digit step alone, Medium ones need the only-square step as well but no guess, Hard ones need a few guesses, and Expert ones need many guesses and many taken back. Every new game shuffles a base puzzle in ways that keep its single answer: the nine digits are renamed, the rows are swapped inside each band of three and the bands are swapped, the columns and stacks the same way, and half the time the grid is turned over on its diagonal (`suNew`, line 558). That is 3,359,232 ways to move the lines (1,296 for the rows, 1,296 for the columns, and the turn) times 362,880 ways to rename the digits, about 1.2 trillion arrangements of each base puzzle, and because the answer is shuffled the same way, it is known at once, so a new game appears without any wait.
- **Play by touch.** Tap a square, then a digit on the 3 x 3 pad at the right; tapping the same digit again erases it, and so do Erase, the 0 key and Del. The arrow keys move the chosen square, and the digit keys place digits (see the key codes in the checklist). The chosen square's row, column and box are shaded, every square holding the same digit is shaded deeper, and a digit of the player's that repeats one in its row, column or box turns red at once. Each key of the pad shows how many of its digit are still to place, and turns gray when all nine are in. A thin bar at the top fills as the grid does, and a row, column or box flashes gold when it is finished (`suFinished`, line 806).
- **Notes (pencil marks), Undo and Check.** With Notes on, the tapped digits become small pencil marks, drawn as 3 x 5 pixel digits in a 3 x 3 pattern inside the square. Placing a digit removes that digit's pencil marks from its row, column and box, and Undo puts them back. The Enter menu can fill in every pencil mark at once, or clear them all, and one Undo reverses either. Check turns the player's wrong digits red without showing the answer.
- **A Hint that says why.** Hint first shows any wrong digit. Otherwise it asks the solver for the tightest spot on the board and explains it in words: either "only a 5 fits the green square, because its row, column and box hold the other 8 digits," or "in row 3, a 7 fits in only one square, the dark green one; the others have a 7 in their column or box" (and the same for a column or a box). When no square can be worked out in one simple step, it shows the square with the fewest choices. Pressing Hint again fills the square in.
- **Watch the solver.** The solver fills the grid from the clues while the student watches, and every digit is colored by the reason it went in: green for the only digit that fits a square, magenta for the only square a digit fits, orange for a guess, and a red flash where a guess is taken back. A key or a tap stops the painting and goes to the end, and Esc then stops the search. At the end the solver's digits keep the color of the step that put them there, so the board shows where the guesses were made, and a bar chart at the right counts each kind of step.
- **A puzzle typed in by touch.** Type (after More) gives an empty grid; a tap on a square and then a digit enters a clue, and the next square is chosen automatically, so a newspaper puzzle goes in row by row, with Erase for each blank square. Play checks that the clues have exactly one answer before the game starts (at least 17 clues, no clue repeated, an answer, and no second answer), and keeps the puzzle in M9. A very hard puzzle can take a while to check, and Esc stops the check; if an answer had already been found, the student may play without the check of a second answer. "Use the puzzle in M9" still takes a puzzle typed into M9 by hand, as beta 1 did.
- **The game is kept.** Esc goes back to the first menu, and the game, its pencil marks, its Undo list and its clock are kept in the program's file-level variables, so Continue (the first item of the first menu) picks it up, even after the program has been left. (A Check or a new copy of the program clears them, as for every program: Lessons Learned 3.)
- **Fireworks** when a puzzle is solved, then the time, the hints and the checks used. The answer of the last puzzle finished is left in `SU_SOLVED`, as in beta 1.
- **Help** in eight pages: how to play, what the colors mean, notes, Undo and Check, hints, Watch, typing a puzzle, keeping the game, and the credits.

## Device checklist (the Virtual Calculator first, then the G1 and the G2)

1. **Check.** Paste into a new program named Sudoku, then Program Catalog, Edit, Check: no message. Run it from Home: the colored SUDOKU title stands behind the first menu, which lists New puzzle: Easy to How to play (Help).
2. **The board.** Choose Easy. Look at the digits in their squares (font 4 at +8, +3 px) and the pencil marks (3 x 5 pixels): are they centered and readable on the G1 and the G2? Are the shades of the chosen row, column and box, and of the same digit, visible on the G1 (Lessons Learned 6: pale tints vanish there)? Are the heavy box lines two pixels wide?
3. **Taps.** Tap a square, then a digit on the pad: the digit should appear in blue. Tap the same digit again: it goes. Tap a clue: the message says clues cannot be changed. Tap each soft key once and see that each does what its name says.
4. **The key codes. Please check these, because beta 2 is the first program to rely on them.** Lessons Learned lists "0=42" among the verified codes, but in HP's key table 42 is the 1 key and 47 is the 0 key, and both community programs that read digits use 1 = 42 and 0 = 47. Beta 2 follows HP's table: 1-9 are 42, 43, 44, 37, 38, 39, 32, 33, 34; 0 is 47; Del is 19; Help is 3. With a square chosen, press 1: a 1 should appear (if it is erased instead, the Lessons Learned line is right and the table in `suPlay` must change). Press 0 and Del: each should erase. Press Help: the help should open. Nothing depends on these keys alone: every action is also on the soft keys, the pad and the Enter menu.
5. **Speed.** Time a tap on the pad, from the tap until the screen changes, on the G1 and on the G2 (the board is drawn whole each time; by an estimate of about 2,500 statements for a drawing and SpeedProbe's figures, that is about 0.4 s on a G1 and 0.13 s on a G2, but only the calculator can say). If the G1 feels slow, say so, and the next version will draw only the squares that change.
6. **Notes and Undo.** Turn Notes on (the pad's digits turn small and gray), put a few pencil marks in squares of one row, turn Notes off and place one of those digits in that row: its pencil marks should leave the row. Undo: they come back.
7. **Hint.** Press Hint on a fresh Easy board: a square turns dark green and its row, column and box light green, with the reason at the right. Press Hint again: the digit goes in. Put a wrong digit somewhere and press Hint: it is shown first, in red.
8. **Finish a puzzle** (Hint again and again is the quick way): the last row, column or box flashes gold, then the fireworks, then the page with the time, hints and checks. A key or a tap leaves it. Esc, then Cancel at the first menu: Home shows the line returned; type SU_SOLVED to see the answer.
9. **Watch.** More, Watch, Watch (ends this game): the digits go in colored, with red flashes on a Hard or Expert puzzle, and the bar chart appears at the end. Try a key in the middle: the painting stops and the end comes sooner. Time a whole Expert Watch on the G1 and on the G2.
10. **Type a puzzle.** More, Type: type in a newspaper puzzle with the pad and Erase, then Play. Record how long the check takes on the G1 and the G2. Then type Easter Monster (from the verify script's list), press Play, and press Esc during the check: the message should say the check was stopped.
11. **Continue.** In the middle of a game, Esc, then Cancel: Home says the game is kept. Run Sudoku again: Continue is first and shows the level and the time; the board comes back as it was.
12. **Dialogs.** Tap OK or Cancel in a menu with the finger held a moment: the board must not take that tap as a soft key (the stale-click guard). Open the Enter menu (13 items; the last ones scroll into view): does Exit Sudoku leave at once?
13. **Message boxes.** Type a puzzle with fewer than 17 clues and press Play; then put a 3 x 3 matrix in M9 and choose Use the puzzle in M9 (that sentence, about 110 characters, is the longest): does each sentence fit its box?
14. **Home settings.** Run `diagnostics/SetOdd_beta1.txt` first (a comma, Fixed 2, Degrees, RPN), then Sudoku: the clock and the counts should still read correctly, with no stray decimals.

## Not yet known, or left for later

- **Nothing has run on a calculator.** Everything above is the PC harness and the Python copies; the device checklist is the next step.
- **The digit key codes** (checklist 4), and the Lessons Learned line that lists 0 = 42.
- **Redraw speed on the G1** (checklist 5). If it is slow, the next version draws only the squares that change.
- **Lennart Börjeson's name** is written "Borjeson" on the help page, because no probe has yet shown that the Prime draws ö in `TEXTOUT_P`; the header, which the calculator never draws, has the ö. One look at the Credits page with an ö would settle it.
- **The clock** shows the time of the last tap or key, and moves on by itself only when `WAIT(-1)` gives up, about once a minute; a clock that ticks every second would need a polling loop, which the Virtual Calculator showed loses key presses.
- **A typed puzzle with very few clues** can take minutes to check on a G1; Esc stops it, and the student can then play without the check of a second answer.
