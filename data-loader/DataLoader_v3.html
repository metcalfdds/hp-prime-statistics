HP Prime Data Loader

Paste columns from Excel, SPSS or a CSV file and get the calculator's own matrix file. The DataLoad program on the Prime then puts each column, or each group's scores, into the Statistics lists that TTestLab, AnovaLab, ScatterLab and the other programs read.

1Paste your data

One variable per column, one case per row. A first row of names is recognized. Empty cells, and cells such as NA or ., become blanks.

2Check the columns

Text columns (such as male / female) are numbered 1, 2, 3 … in alphabetical order, as the codes column shows: the calculator holds numbers only. Write the codes down; DataLoad puts the smallest code's scores in D1.

The Virtual Calculator (Windows)

  1. Close the Virtual Calculator (its Calculator menu, Exit). It reads its folder only when it starts.
  2. Copy M1.hpmat into Documents\HP Prime\Calculators\Prime; if the file came in a zip, unzip it first. Replace the file that is there.
  3. Start the calculator, open the Statistics 1Var app once (Apps), then run DataLoad from the Program Catalog and choose Columns or Scores by group.
  4. If DataLoad says lists after the new ones hold data from before, choose clear: AnovaLab, RankLab and AgreeLab read every list that holds data as one more group (or rater).

Tested on the Virtual Calculator 2.4.2 (build 2026-09-09), 31 Oct 2026: the example's 432 rows × 5 columns arrived whole, DataLoad put them in D1–D5 and the weeks by financial aid in D1 and D2, and TTestLab read those two lists (separate-variances t(421.19) = −1.68, p = 0.094). DataLoad is in the starter pack; the first time, Check it once in the Program Catalog.

A G1 or G2

  1. Connect the calculator to the HP Connectivity Kit.
  2. Drag M1.hpmat onto the calculator in the Kit, or open its matrix M1 there and paste the columns.
  3. Run DataLoad on the calculator.

Not yet tested on a G1 or G2. Large data sets load slowly over the Kit; send one matrix at a time.

Part of hp-prime-statistics, Roger Metcalf's teaching programs for the HP Prime. Written with AI assistance (Anthropic Claude). Free for educational and personal use. A teaching aid: not validated for forensic, clinical or legal use.

Everything happens in this page; nothing you paste leaves your computer. Numbers are read from their digits and rounded to the Prime's 12 significant digits, half up. The file format is the one hp-prime-kit (JordiRigau/hp-prime-kit, MIT) documents. Blank cells are written as 9.99999999999E499, the Prime's largest real, which DataLoad leaves out.

Example data: Rossi, Berk & Lenihan (1980), Money, Work, and Crime: 432 men released from Maryland state prisons, followed 52 weeks (week of first re-arrest, arrest 1/0, financial aid 1/0, age, prior convictions), via the R package carData.
