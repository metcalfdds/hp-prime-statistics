// SEIZURELAB - beta 1a  (21 Oct 2026)
// Representative sampling of a drug seizure, for a forensic-science or
//   criminal-justice class.  A laboratory receives N similar units
//   (packets, tablets) and cannot test them all.  How many must it test
//   to support, at confidence c, the claim that AT LEAST a proportion p0
//   of the N contain the drug?  And, from the weights of the units it
//   did test, what is the total net weight of the seizure?
// Launch: SeizureLab() from the Program Catalog (no arguments; it opens
//   on a title page, then its menu).  Menu items:
//     Set up: N, c, p0, prior     one INPUT form (N, c, p0, negatives
//                                 allowed, prior a and b)
//     Hypergeometric: n to test   the exact frequentist answer, the
//                                 least n for 0, 1, 2 negatives, the
//                                 lower confidence bound, a bar chart
//     Binomial approximation      the large-N answer beside the exact
//                                 one, and a plot of both against n
//     Bayesian (beta prior)       Aitken's (1999) beta-binomial answer,
//                                 prior and posterior densities
//     OC curve: drag n            P(the claim is supported) against the
//                                 TRUE proportion; drag n with a finger
//     Weight: total net weight    t interval for the total with the
//                                 finite-population correction
//     Tables: n for N = 10 to inf the least n, computed live
//     Enter a result: n and x     what was tested and what was found
//     Help                        eight pages
//   Home exports after a run: SZ_N (N), SZ_NMIN (least n, all positive,
//   hypergeometric), SZ_P (P(X >= x | K0) for the result shown), SZ_LB
//   (lower confidence bound for the proportion), SZ_PB (the Bayesian
//   posterior probability of the claim), SZ_TOT and SZ_TLB (the total
//   weight and its one-sided lower bound).
// Written for the 2026-09-09 firmware (HP Prime G2 and G1).  beta 1 has
//   NOT been run on hardware or the emulator, only in the PC harness.
// Sources: every formula below was derived here from first principles
//   and checked numerically against SciPy (hypergeom, binom, betabinom,
//   beta, t); no number in this file was taken from a paper.
//   ENFSI Drugs Working Group (2009) Guidelines on Representative Drug
//     Sampling, UNODC ST/NAR/38,
//     https://www.unodc.org/documents/scientific/Drug_Sampling.pdf
//     (READ for beta 1a, by the second review: its hypergeometric,
//     binomial and Bayesian tables (1-5) agree with this program in 426
//     of 427 cells, the one exception being the guideline's own misprint,
//     see the NOTES; its Table 4 tabulates the Bayesian answer for a
//     large seizure, "N >= 50" assumed, which is this program's N -> inf
//     value; its section 7 gives the weight interval with the factor
//     sqrt((N - n)/N), used here since beta 1a);
//   Cochran WG (1977) Sampling Techniques, 3rd ed., Wiley (the variance of
//     a mean under sampling without replacement);
//   SWGDRUG Recommendations (sampling).
//   Cited for the METHOD only and NOT checked against the papers here
//   (their references match ENFSI's list):
//   Aitken CGG (1999) Sampling - how big a sample?  J Forensic Sci
//     44(4):750-760 (the beta prior and the beta-binomial for the
//     untested units);
//   Coulson SA et al. (2001) How many samples from a drug seizure need to
//     be analyzed?  J Forensic Sci 46(6):1456-1461;
//   Tzidony D, Ravreby M (1992) A statistical approach to drug sampling:
//     a case study.  J Forensic Sci 37(6):1541-1549 (ENFSI's reference
//     list also carries Stoel RD, Bolck A, "A correction to Tzidony and
//     Ravreby (1992)", J Forensic Sci, in press in 2009; not read here);
//   Frank RS et al. (1991) Representative sampling of drug seizures in
//     multiple containers.  J Forensic Sci 36(2):350-357 (its multi-

//   Lanczos log-gamma: the g = 7, 9-coefficient set (Godfrey), as in

// Data: no data set from data/DATASETS.md fits (none is a drug seizure).
//   The weight page's example is labelled on screen "illustrative

// Replaces / reworks: the Triola TI-83/84 programs OCBIN, OCHYPER and

//   not repeated: OCBIN, OCHYPER and OCPOISSN draw the PMF (binompdf,

// beta 1a (21 Oct 2026): the second review's findings (REVIEW2, items
//   1-13; SeizureLab_beta1a_CHANGES.md has one line each).  The Bayesian
//   least-n searches are bisections and Esc stops them, with a moving
//   bar (1); the weight factor is sqrt((N - n)/N) (2, Roger's D1); the
//   Bayesian page shows the finite-N and N -> inf least n side by side

//   unchecked (11); a help page "Checking against ENFSI" (2, 3).
// File map: (line ranges, beta 1a)
//      1-  293  header, the arithmetic, Home exports, file-level LOCALs
//    294-  537  small helpers: init, drains, waits, formats, frames, axes
//    538-  995  numerics: log-gamma, sums of positive terms, searches

// THE ARITHMETIC (derived here; see the NOTES file for the checks)
//   The seizure: N units, K of them contain the drug (unknown).  The
//   CLAIM "at least a proportion p0 contain drug" is K/N >= p0, that is
//   K >= Kr with Kr = ceiling(p0 N) (K is whole).  K0 = Kr - 1 is the
//   LARGEST K for which the claim is false.  When p0 N is whole (N = 100,
//   p0 = 0.90: Kr = 90, K0 = 89) the claim allows K = 90 exactly; when it
//   is not (N = 15, p0 = 0.90: p0 N = 13.5, Kr = 14, K0 = 13) K = 13 is
//   below 13.5 and is false.  p0 N is rounded to 6 decimals before the
//   ceiling, so 0.07 x 100 is 7, not 8 (binary arithmetic on a PC).
//
//   1. HYPERGEOMETRIC.  Test n units chosen at random; X = the number
//   positive.  Given K, X is hypergeometric:
//     P(X = k) = C(K, k) C(N - K, n - k) / C(N, n).
//   Observing x positive, the claim is SUPPORTED at confidence c when
//     P(X >= x | N, n, K0) <= 1 - c.
//   P(X >= x | K) grows with K (more positives in the seizure, more in the
//   sample), so if the result is that rare at K0 it is rarer still for
//   every K < K0: K0 is the worst false case.  This is a one-sided test of
//   H0: K <= K0, and "supported" means H0 is rejected at level 1 - c.
//   Least n with all positive (x = n): the smallest n with
//     P(X = n | K0) = C(K0, n) / C(N, n) <= 1 - c;
//   with d negatives allowed (x = n - d), the smallest n with
//     P(X >= n - d | K0) = P(at most d negatives) <= 1 - c.
//   P(at most d negatives) falls as n grows (each extra unit can only add
//   a negative), so the search is a bisection on [d + 1, N]; at n = N the
//   sample is the seizure, so a solution exists exactly when N - K0 > d.
//   LOWER CONFIDENCE BOUND: the smallest K still consistent with what was
//   seen, K_L = min{K : P(X >= x | K) > 1 - c}, K in [x, N - (n - x)]
//   (bisection, the same monotonicity); the claim is supported exactly
//   when Kr <= K_L.  K_L / N is a one-sided lower confidence bound at c
//   for the proportion of drug units (the exact, Clopper-Pearson-style
//   bound for sampling without replacement).
//
//   2. BINOMIAL.  For large N the units drawn hardly change what is left,
//   so X is close to Binomial(n, p0), tested at p0 itself (the supremum
//   over the false proportions below p0).  All positive: p0^n <= 1 - c,
//   n >= ln(1 - c)/ln(p0).  With d negatives: P(at most d negatives) =
//   sum_{j<=d} C(n, j)(1 - p0)^j p0^(n - j) <= 1 - c.  It does not depend
//   on N; it is the hypergeometric's limit as N grows.
//
//   3. BAYESIAN (Aitken 1999; ENFSI 2009).  A prior Beta(a, b) on the
//   proportion theta of drug units (uniform: a = b = 1; Jeffreys: a = b =
//   0.5).  After n tested with x positive the posterior is
//   Beta(a + x, b + n - x), and the number Y of positives among the
//   m = N - n UNTESTED units is beta-binomial:
//     P(Y = y) = C(m, y) B(y + a + x, m - y + b + n - x) / B(a + x, b + n - x).
//   P(claim | data) = P(x + Y >= Kr) = P(Y >= Kr - x)  (1 if Kr <= x, 0 if
//   Kr - x > m).  Least n with all positive: the smallest n with
//   P(Y >= Kr - n | m = N - n, a + n, b) >= c (beta 1a: a bisection,
//   bracketed by doubling steps from the large-N guess, bounded by 0 and
//   min(N, Kr), where the probability is 1; the condition is monotone in
//   n, checked on the verify grid).  Check (uniform prior, all positive): the posterior of K is
//   proportional to C(K, n), so P(claim) = 1 - C(Kr, n + 1)/C(N + 1, n + 1)
//   (the hockey-stick identity); the verify script compares.
//   As N grows the claim becomes theta >= p0, with probability
//     P(theta >= p0 | data) = I_{1-p0}(b + n - x, a + x)
//   (the regularized incomplete beta; the shaded area of the posterior).
//   This N -> inf form is what ENFSI's Table 4 tabulates ("a large
//   seizure is assumed", N >= 50): 28 for a uniform prior, p0 = 0.90,
//   c = 0.95; for N = 100 the beta-binomial above gives 22, because it
//   counts only the untested units of this seizure.  The page shows both.
//
//   4. OC CURVE.  The plan "test n, support the claim if at most d are
//   negative" supports it with probability
//     OC(K) = P(X >= n - d | N, n, K)
//   when K of the N are drug.  Drawn against the true proportion K/N; the
//   red part (K <= K0) is the chance of supporting a FALSE claim, at most
//   OC(K0), which is <= 1 - c when n is at least the least n.  The thin
//   blue curve is the binomial OC, sum_{j<=d} C(n,j)(1-t)^j t^(n-j).
//
//   5. WEIGHT (ENFSI's second question).  From the net weights w of the n
//   tested units: mean w-bar, SD s (n - 1 divisor).  Total T = N w-bar.
//   SE(T) = N (s / sqrt n) sqrt((N - n)/N).
//   (Derivation: without replacement Var(w-bar) = (S^2 / n)(N - n)/N with
//   S^2 the population variance on N - 1 (Cochran); s^2 estimates S^2, so
//   the unbiased factor is (N - n)/N.  beta 1 used (N - n)/(N - 1), which
//   belongs to a variance with divisor N and overstates Var(T) by
//   N/(N - 1); Roger's decision D1 (21 Oct 2026) and ENFSI section 7,
//   whose example prints the factor 0.877 = sqrt(77/100), settle it; the
//   second review's simulation agrees.)  Two-sided CI:
//   T +/- t(n - 1, (1 + c)/2) SE; one-sided lower bound: T - t(n - 1, c) SE
//   (the number a court may ask for: "at least ... g").
//
// NUMERICS
//   ln Gamma by Lanczos (g = 7, 9 terms; relative error about 1E-15 in
//   double, the Prime's 12 digits otherwise).  Every probability is a SUM
//   OF POSITIVE TERMS: one term is computed from log-gammas at the LARGEST
//   term of the range (the mode, clamped into it), the others by the
//   ratio of neighbours, walking away from it in both directions and
//   stopping when a term is below 1E-16 of the sum (terms only fall away
//   from the mode).  Nothing is computed as 1 - (a sum), so nothing
//   cancels (Lessons Learned 3); a log below -1100 is a probability
//   below 1E-477, returned as 0 (no underflow, no overflow: N up to
//   10,000 is allowed, and the sums were checked to N = 1,000,000).
//   The beta-binomial is unimodal when a + b + n > 2, monotone at 2 and
//   U-shaped below (Jeffreys with n = 0); a U-shaped sum starts at the
//   larger end and is never cut short.  The incomplete beta uses the
//   continued fraction (no alternating sum).
//
// HOME EXPORTS
//   SZ_N, SZ_NMIN, SZ_P, SZ_LB, SZ_PB, SZ_TOT, SZ_TLB (see above).
//
// LAYOUT
//   Font 1 is about 6.5 px per character: text lines are at most 46
//   characters from x = 6, and every TEXTOUT_P is given a width.  Result
//   pages: title band 0-17, text from y 20 every 12 px, the plot, a
//   legend or tap line at y 192, the one-line disclaimer at y 204, the
//   soft keys from y 220.
//
// SPEED (untested on a G1; see the NOTES checklist)
//   The beta-binomial sum has up to N(1 - p0) terms; at N = 10,000 a
//   Bayesian search (about 2 log2(N) sums at worst) can take a minute or
//   more on a G1 (estimated from the PC harness at 30-100x; not timed on
//   a G1), so the program says "Computing ..." with a moving bar and Esc
//   stops it.  The OC curve keeps ln Gamma(K + 1) per pixel
//   column for the current N, so one frame costs one ln Gamma per column;
//   while a finger drags n it computes every fourth column and leaves
//   the binomial curve out until the finger lifts.
// ============================================================

// Wait for the finger to lift, never more than one second
// (Lessons Learned 7: a stuck touch reading must not freeze the program).
sz_Drain()
BEGIN
  LOCAL drT;
  drT := TICKS;
  REPEAT UNTIL MOUSE(1) == -1 OR TICKS - drT > 1000;
END;

// Drain, wait for a key OR a tap, drain.  Returns the key code, or -1
// for a tap.
sz_WaitAny()
BEGIN
  LOCAL waK, waM, waM1, waK2;
  REPEAT waK := GETKEY; UNTIL waK == -1;
  sz_Drain();
  REPEAT
    waK := GETKEY;
    waM := MOUSE;
    waM1 := waM(1);
  UNTIL waK > -1 OR SIZE(waM1) > 0;
  IF SIZE(waM1) > 0 THEN waK := -1; END;
  sz_Drain();
  REPEAT waK2 := GETKEY; UNTIL waK2 == -1;
  RETURN waK;
END;

// A 1, 2 or 5 times a power of ten at least as big as v (Heckbert).
sz_Nice(nvV)
BEGIN
  LOCAL nvE, nvF;
  IF nvV <= 0 THEN RETURN 1; END;
  nvE := FLOOR(LOG(nvV));
  nvF := nvV / 10^nvE;
  // a hair of slack: 0.2 / 0.1 is 2.0000000000000004 in binary
  IF nvF <= 1.000001 THEN RETURN 10^nvE; END;
  IF nvF <= 2.000001 THEN RETURN 2 * 10^nvE; END;
  IF nvF <= 5.000001 THEN RETURN 5 * 10^nvE; END;
  RETURN 10^(nvE + 1);
END;

// A whole number as text ("23").
sz_I(ivV)
BEGIN
  RETURN STRING(ROUND(ivV, 0) + 0, 2, 0);
END;

// A number with d fixed decimals, rounded first, so it can never turn
// scientific (Lessons Learned 3); "+ 0" turns a rounded -0 into 0.
sz_F(fvV, fvD)
BEGIN
  RETURN STRING(ROUND(fvV, fvD) + 0, 2, fvD);
END;

// A short number with as few decimals as it needs, from dvMin up to 4
// (0.9 with dvMin 2 is "0.90"; 23.5 with dvMin 0 is "23.5").
sz_G(gvV, gvMin)
BEGIN
  LOCAL gvD;
  FOR gvD FROM gvMin TO 4 DO
    IF ABS(gvV - ROUND(gvV, gvD)) < 0.000000001 THEN RETURN sz_F(gvV, gvD); END;
  END;
  RETURN sz_F(gvV, 4);
END;

// A probability with its relation: "= 0.0402", "< 0.0001", "> 0.9999",
// "= 0" (impossible), "= 1" (certain).
sz_PStr(psP)
BEGIN
  IF psP <= 0 THEN RETURN "= 0"; END;
  IF psP >= 1 THEN RETURN "= 1"; END;
  IF psP < 0.0001 THEN RETURN "< 0.0001"; END;
  IF psP > 0.9999 THEN RETURN "> 0.9999"; END;
  RETURN "= " + sz_F(psP, 4);
END;

// A least n as text: "none" when no n works, "stopped" after Esc.
sz_NStr(nsV)
BEGIN
  IF nsV == -2 THEN RETURN "stopped"; END;
  IF nsV < 0 THEN RETURN "none"; END;
  RETURN sz_I(nsV);
END;

// A weight with decimals that suit its size.
sz_W(wfV)
BEGIN
  IF ABS(wfV) < 1 THEN RETURN sz_F(wfV, 4); END;
  IF ABS(wfV) < 10 THEN RETURN sz_F(wfV, 3); END;
  IF ABS(wfV) < 1000 THEN RETURN sz_F(wfV, 2); END;
  IF ABS(wfV) < 100000 THEN RETURN sz_F(wfV, 1); END;

// ln Gamma(z), z > 0, by Lanczos (g = 7, nine terms):
//   Gamma(z) = sqrt(2 pi) t^(z - 1/2) e^(-t) A(z),  t = z + 6.5,
//   A(z) = c0 + sum_{i=1..8} c_i / (z - 1 + i).
// Below 0.5 it steps up with ln Gamma(z) = ln Gamma(z + 1) - ln z.
// LNGAMMA does not exist outside the CAS (Lessons Learned 3).
sz_LnG(lgZ)
BEGIN
  LOCAL lgW, lgS, lgX, lgA, lgI, lgT;
  IF lgZ <= 0 THEN RETURN 0; END;
  lgW := lgZ; lgS := 0;
  WHILE lgW < 0.5 DO
    lgS := lgS - LN(lgW);
    lgW := lgW + 1;
  END;
  lgX := lgW - 1;
  lgA := szLc(1);
  FOR lgI FROM 1 TO 8 DO
    lgA := lgA + szLc(lgI + 1) / (lgX + lgI);
  END;
  lgT := lgX + 7.5;
  RETURN lgS + 0.918938533204673 + (lgX + 0.5) * LN(lgT) - lgT + LN(lgA);
END;

// ln C(a, b) for whole 0 <= b <= a.
sz_LnC(lcA, lcB)
BEGIN
  RETURN sz_LnG(lcA + 1) - sz_LnG(lcB + 1) - sz_LnG(lcA - lcB + 1);
END;

// ln B(p, q) = ln Gamma(p) + ln Gamma(q) - ln Gamma(p + q).
sz_LnB(lbP, lbQ)
BEGIN
  RETURN sz_LnG(lbP) + sz_LnG(lbQ) - sz_LnG(lbP + lbQ);
END;

// P(lo <= X <= hi), X hypergeometric: the positives in a sample of hsSam
// from hsPop units of which hsPos are positive.  The largest term in the
// range (the mode, (n+1)(K+1)/(N+2) rounded down, clamped into it) comes
// from log-gammas; the rest by
//   P(k+1)/P(k) = (K - k)(n - k) / ((k + 1)(N - K - n + k + 1)),
// walking away from it both ways; positive terms only.
sz_HypS(hsPop, hsPos, hsSam, hsLo, hsHi)
BEGIN
  LOCAL hsL, hsH, hsM, hsA, hsLa, hsT0;
  LOCAL hsS, hsT, hsK;
  hsL := MAX(hsLo, MAX(0, hsSam - (hsPop - hsPos)));
  hsH := MIN(hsHi, MIN(hsSam, hsPos));
  IF hsL > hsH THEN RETURN 0; END;
  hsM := FLOOR((hsSam + 1) * (hsPos + 1) / (hsPop + 2));
  hsA := MIN(MAX(hsM, hsL), hsH);
  hsLa := sz_LnC(hsPos, hsA) + sz_LnC(hsPop - hsPos, hsSam - hsA) - sz_LnC(hsPop, hsSam);
  IF hsLa < -1100 THEN RETURN 0; END;
  hsT0 := EXP(hsLa);
  hsS := hsT0;
  // upwards from the largest term
  hsT := hsT0; hsK := hsA;
  WHILE hsK < hsH DO
    hsT := hsT * (hsPos - hsK) * (hsSam - hsK) / ((hsK + 1) * (hsPop - hsPos - hsSam + hsK + 1));
    hsK := hsK + 1;
    hsS := hsS + hsT;
    IF hsT < 1E-16 * hsS THEN hsK := hsH; END;
  END;
  // downwards from it
  hsT := hsT0; hsK := hsA;
  WHILE hsK > hsL DO
    hsT := hsT * hsK * (hsPop - hsPos - hsSam + hsK) / ((hsPos - hsK + 1) * (hsSam - hsK + 1));
    hsK := hsK - 1;
    hsS := hsS + hsT;
    IF hsT < 1E-16 * hsS THEN hsK := hsL; END;
  END;
  RETURN MIN(hsS, 1);
END;

// The hypergeometric probabilities P(X = k) for k = hlK1..hlK2, as a
// list (0 outside the possible range); same anchor and ratios.
sz_HypL(hlPop, hlPos, hlSam, hlK1, hlK2)
BEGIN
  LOCAL hlL, hlH, hlA, hlT, hlK, hlOut;
  LOCAL hlI;
  hlOut := MAKELIST(0, hlI, 1, hlK2 - hlK1 + 1);
  hlL := MAX(hlK1, MAX(0, hlSam - (hlPop - hlPos)));
  hlH := MIN(hlK2, MIN(hlSam, hlPos));
  IF hlL > hlH THEN RETURN hlOut; END;
  hlA := MIN(MAX(FLOOR((hlSam + 1) * (hlPos + 1) / (hlPop + 2)), hlL), hlH);
  hlT := sz_LnC(hlPos, hlA) + sz_LnC(hlPop - hlPos, hlSam - hlA) - sz_LnC(hlPop, hlSam);
  IF hlT < -1100 THEN RETURN hlOut; END;
  hlT := EXP(hlT);
  hlOut(hlA - hlK1 + 1) := hlT;
  hlK := hlA;
  WHILE hlK < hlH DO
    hlT := hlT * (hlPos - hlK) * (hlSam - hlK) / ((hlK + 1) * (hlPop - hlPos - hlSam + hlK + 1));
    hlK := hlK + 1;
    hlOut(hlK - hlK1 + 1) := hlT;
  END;
  hlT := hlOut(hlA - hlK1 + 1); hlK := hlA;
  WHILE hlK > hlL DO
    hlT := hlT * hlK * (hlPop - hlPos - hlSam + hlK) / ((hlPos - hlK + 1) * (hlSam - hlK + 1));
    hlK := hlK - 1;
    hlOut(hlK - hlK1 + 1) := hlT;
  END;
  RETURN hlOut;
END;

// ln P(Y = y), Y beta-binomial(m, al, be).
sz_BBLp(blM, blAl, blBe, blY)
BEGIN
  RETURN sz_LnC(blM, blY) + sz_LnB(blY + blAl, blM - blY + blBe) - sz_LnB(blAl, blBe);
END;

// P(lo <= Y <= hi), Y beta-binomial(m, al, be), from positive terms:
//   P(y+1)/P(y) = (m - y)(y + al) / ((y + 1)(m - y - 1 + be)).
// That ratio is above 1 exactly while y < y* = (m(al - 1) + 1 - be) /
// (al + be - 2) when al + be > 2 (one peak, at ceiling(y*)); with
// al + be = 2 the terms only rise (al > 1) or only fall; below 2 they
// fall and rise again (U-shape), so the sum starts at the larger end and
// is never cut short.
sz_BBS(bbM, bbAl, bbBe, bbLo, bbHi)
BEGIN
  LOCAL bbL, bbH, bbA, bbTr, bbYs, bbLa;
  LOCAL bbT0, bbS, bbT, bbY;
  bbL := MAX(bbLo, 0); bbH := MIN(bbHi, bbM);
  IF bbL > bbH THEN RETURN 0; END;
  bbTr := 1;
  IF bbAl + bbBe > 2 THEN
    bbYs := (bbM * (bbAl - 1) + 1 - bbBe) / (bbAl + bbBe - 2);
    bbA := MIN(MAX(CEILING(bbYs), bbL), bbH);
  ELSE
    IF bbAl + bbBe < 2 THEN
      bbTr := 0;
      bbA := bbL;
      IF sz_BBLp(bbM, bbAl, bbBe, bbH) > sz_BBLp(bbM, bbAl, bbBe, bbL) THEN bbA := bbH; END;
    ELSE
      bbA := bbL;
      IF bbAl > 1 THEN bbA := bbH; END;
    END;
  END;
  bbLa := sz_BBLp(bbM, bbAl, bbBe, bbA);
  IF bbLa < -1100 THEN RETURN 0; END;
  bbT0 := EXP(bbLa);
  bbS := bbT0;
  bbT := bbT0; bbY := bbA;
  WHILE bbY < bbH DO
    bbT := bbT * (bbM - bbY) * (bbY + bbAl) / ((bbY + 1) * (bbM - bbY - 1 + bbBe));
    bbY := bbY + 1;
    bbS := bbS + bbT;
    IF bbTr == 1 THEN
      IF bbT < 1E-16 * bbS THEN bbY := bbH; END;
    END;
  END;
  bbT := bbT0; bbY := bbA;
  WHILE bbY > bbL DO
    bbT := bbT * bbY * (bbM - bbY + bbBe) / ((bbM - bbY + 1) * (bbY - 1 + bbAl));
    bbY := bbY - 1;
    bbS := bbS + bbT;
    IF bbTr == 1 THEN
      IF bbT < 1E-16 * bbS THEN bbY := bbL; END;
    END;
  END;
  RETURN MIN(bbS, 1);
END;

// P(lo <= X <= hi), X binomial(n, p): the same anchor-and-ratio sum,
//   P(k+1)/P(k) = (n - k)/(k + 1) * p/(1 - p).
sz_BinS(bsSam, bsP, bsLo, bsHi)
BEGIN
  LOCAL bsL, bsH, bsQ, bsA, bsLa, bsT0;
  LOCAL bsS, bsT, bsK;
  bsL := MAX(bsLo, 0); bsH := MIN(bsHi, bsSam);
  IF bsL > bsH THEN RETURN 0; END;
  IF bsP <= 0 THEN
    IF bsL == 0 THEN RETURN 1; END;
    RETURN 0;
  END;
  IF bsP >= 1 THEN
    IF bsH == bsSam THEN RETURN 1; END;
    RETURN 0;
  END;
  bsQ := 1 - bsP;
  bsA := MIN(MAX(MIN(FLOOR((bsSam + 1) * bsP), bsSam), bsL), bsH);
  bsLa := sz_LnC(bsSam, bsA) + bsA * LN(bsP) + (bsSam - bsA) * LN(bsQ);
  IF bsLa < -1100 THEN RETURN 0; END;
  bsT0 := EXP(bsLa);
  bsS := bsT0;
  bsT := bsT0; bsK := bsA;
  WHILE bsK < bsH DO
    bsT := bsT * (bsSam - bsK) / (bsK + 1) * bsP / bsQ;
    bsK := bsK + 1;
    bsS := bsS + bsT;
    IF bsT < 1E-16 * bsS THEN bsK := bsH; END;
  END;
  bsT := bsT0; bsK := bsA;
  WHILE bsK > bsL DO
    bsT := bsT * bsK / (bsSam - bsK + 1) * bsQ / bsP;
    bsK := bsK - 1;
    bsS := bsS + bsT;
    IF bsT < 1E-16 * bsS THEN bsK := bsL; END;
  END;
  RETURN MIN(bsS, 1);
END;

// The continued fraction of the incomplete beta (Numerical Recipes
// 6.4, betacf, modified Lentz), at most 300 steps.
sz_BetaCF(cfA, cfB, cfX)
BEGIN
  LOCAL cfQb, cfQp, cfQm, cfC, cfD, cfH;
  LOCAL cfM, cfM2, cfAa, cfDe, cfGo;
  cfQb := cfA + cfB; cfQp := cfA + 1; cfQm := cfA - 1;
  cfC := 1;
  cfD := 1 - cfQb * cfX / cfQp;
  IF ABS(cfD) < 1E-300 THEN cfD := 1E-300; END;
  cfD := 1 / cfD;
  cfH := cfD;
  cfM := 1; cfGo := 1;
  WHILE cfGo == 1 DO
    cfM2 := 2 * cfM;
    cfAa := cfM * (cfB - cfM) * cfX / ((cfQm + cfM2) * (cfA + cfM2));
    cfD := 1 + cfAa * cfD;
    IF ABS(cfD) < 1E-300 THEN cfD := 1E-300; END;
    cfC := 1 + cfAa / cfC;
    IF ABS(cfC) < 1E-300 THEN cfC := 1E-300; END;
    cfD := 1 / cfD;
    cfH := cfH * cfD * cfC;
    cfAa := -(cfA + cfM) * (cfQb + cfM) * cfX / ((cfA + cfM2) * (cfQp + cfM2));
    cfD := 1 + cfAa * cfD;
    IF ABS(cfD) < 1E-300 THEN cfD := 1E-300; END;
    cfC := 1 + cfAa / cfC;
    IF ABS(cfC) < 1E-300 THEN cfC := 1E-300; END;
    cfD := 1 / cfD;
    cfDe := cfD * cfC;
    cfH := cfH * cfDe;
    IF ABS(cfDe - 1) < 1E-13 OR cfM >= 300 THEN cfGo := 0; END;
    cfM := cfM + 1;
  END;
  RETURN cfH;
END;

// The regularized incomplete beta I_x(a, b) = P(Beta(a, b) <= x).
// Below the mean the fraction converges fast and gives the small value
// directly; above it, 1 - (the mirror), which is then at least about a
// half, so the subtraction loses nothing.
sz_IBeta(ibX, ibA, ibB)
BEGIN
  LOCAL ibLf;
  IF ibX <= 0 THEN RETURN 0; END;
  IF ibX >= 1 THEN RETURN 1; END;
  ibLf := ibA * LN(ibX) + ibB * LN(1 - ibX) - sz_LnB(ibA, ibB);
  IF ibX < (ibA + 1) / (ibA + ibB + 2) THEN
    RETURN EXP(ibLf) * sz_BetaCF(ibA, ibB, ibX) / ibA;
  END;
  RETURN 1 - EXP(ibLf) * sz_BetaCF(ibB, ibA, 1 - ibX) / ibB;
END;

// The comparisons with 1 - c and with c.  An exact tie counts as met, as
// in exact arithmetic: with N = 10, K0 = 9, n = 9 the probability is
// exactly 1/10 and c = 0.90 makes 1 - c exactly 1/10, but the computed
// value can come out a little high.  On the Prime every tail is EXP of a
// difference of large ln-gammas held to 12 digits, so it is good to about
// 2E-7 (relative) at N = 10,000 (second review, item 4: a 12-digit
// emulation gave 0.0500000046777 for an exact 0.05 at N = 5000).  beta 1a
// allows 1E-6 relative to 1 - c, the scale that matters (beta 1: 1E-9):
// P <= (1 - c)(1 + 1E-6), and P >= c - 1E-6 (1 - c).  (Relative to c the
// window would be 1% of 1 - c at c = 0.9999 and would move a least n:
// 5665 instead of 5668 at N = 10000, p0 = 0.999, uniform prior.)  The
// price: a probability up to 1E-6 (relative to 1 - c) on the wrong side
// also counts as met; the pages show 4 decimals, so no displayed verdict
// can contradict its number.
sz_Le(leP, leA)
BEGIN
  IF leP <= leA + 0.000001 * leA THEN RETURN 1; END;
  RETURN 0;
END;

sz_Ge(gePr, geC)
BEGIN
  IF gePr >= geC - 0.000001 * (1 - geC) THEN RETURN 1; END;
  RETURN 0;
END;

// Kr = ceiling(p0 N): the claim is K >= Kr.  p0 N is rounded to six
// decimals first (0.07 x 100 is 7.000000000000001 in binary).
sz_KrOf(krPop, krP)
BEGIN
  RETURN CEILING(ROUND(krP * krPop, 6));
END;

// Least n (hypergeometric) with at most hmD negatives: the smallest n
// with P(X >= n - d | N, n, K0) <= 1 - c, by bisection on [d + 1, N];
// -1 when even n = N does not do it (N - K0 <= d).
sz_HypMin(hmPop, hmC, hmP, hmD)
BEGIN
  LOCAL hmK0, hmA, hmLo, hmHi, hmMid;
  hmK0 := sz_KrOf(hmPop, hmP) - 1;
  hmA := 1 - hmC;
  hmLo := hmD + 1;
  IF hmLo > hmPop THEN RETURN -1; END;
  IF sz_Le(sz_HypS(hmPop, hmK0, hmPop, hmPop - hmD, hmPop), hmA) == 0 THEN RETURN -1; END;
  hmHi := hmPop;
  WHILE hmLo < hmHi DO
    hmMid := FLOOR((hmLo + hmHi) / 2);
    IF sz_Le(sz_HypS(hmPop, hmK0, hmMid, hmMid - hmD, hmMid), hmA) == 1 THEN
      hmHi := hmMid;
    ELSE
      hmLo := hmMid + 1;
    END;
  END;
  RETURN hmLo;
END;

// Least n (binomial, any N) with at most bmD negatives: the smallest n
// with P(Binomial(n, 1 - p0) <= d) <= 1 - c.  Doubling from the d = 0
// answer, then bisection; -1 past 4,000,000.
sz_BinMin(bmC, bmP, bmD)
BEGIN
  LOCAL bmA, bmLo, bmHi, bmMid;
  bmA := 1 - bmC;
  bmLo := bmD + 1;
  bmHi := MAX(bmD + 1, CEILING(LN(bmA) / LN(bmP)));
  WHILE sz_Le(sz_BinS(bmHi, 1 - bmP, 0, bmD), bmA) == 0 DO
    bmLo := bmHi + 1;
    bmHi := bmHi * 2;
    IF bmHi > 4000000 THEN RETURN -1; END;
  END;
  WHILE bmLo < bmHi DO
    bmMid := FLOOR((bmLo + bmHi) / 2);
    IF sz_Le(sz_BinS(bmMid, 1 - bmP, 0, bmD), bmA) == 1 THEN bmHi := bmMid; ELSE bmLo := bmMid + 1; END;
  END;
  RETURN bmLo;
END;

// The lower confidence bound: the smallest K with P(X >= x | K) > 1 - c,
// K from x to N - (n - x) (where the probability is 1).
sz_LowB(lwPop, lwSam, lwX, lwC)
BEGIN
  LOCAL lwA, lwLo, lwHi, lwMid;
  IF lwX <= 0 THEN RETURN 0; END;
  lwA := 1 - lwC;
  lwLo := lwX; lwHi := lwPop - (lwSam - lwX);
  WHILE lwLo < lwHi DO
    lwMid := FLOOR((lwLo + lwHi) / 2);
    IF sz_Le(sz_HypS(lwPop, lwMid, lwSam, lwX, lwSam), lwA) == 0 THEN lwHi := lwMid; ELSE lwLo := lwMid + 1; END;
  END;
  RETURN lwLo;
END;

// The posterior probability of the claim, finite N:
// P(Y >= Kr - x), Y beta-binomial(N - n, a + x, b + n - x).
sz_BayP(bpPop, bpSam, bpX, bpP, bpA, bpB)
BEGIN
  LOCAL bpKr, bpT, bpM;
  bpKr := sz_KrOf(bpPop, bpP);
  bpT := bpKr - bpX; bpM := bpPop - bpSam;
  IF bpT <= 0 THEN RETURN 1; END;
  IF bpT > bpM THEN RETURN 0; END;
  RETURN sz_BBS(bpM, bpA + bpX, bpB + bpSam - bpX, bpT, bpM);
END;

// The same as N grows: P(theta >= p0) under Beta(a + x, b + n - x)
// = I_{1 - p0}(b + n - x, a + x).
sz_BayL(blSam, blX, blP, blA, blB)
BEGIN
  RETURN sz_IBeta(1 - blP, blB + blSam - blX, blA + blX);
END;

// Between two sums of a long search: one more tick on the busy box's
// progress strip (drawn straight on the screen, a 3-pixel block that
// sweeps 40..280 and starts again), then GETKEY: Esc sets szStop, and
// every search still running returns -2 ("stopped").  Callers set szStop
// to 0 before they start.
sz_EscHit()
BEGIN
  LOCAL ehX;
  szPrg := szPrg + 1;
  ehX := 40 + 4 * (szPrg - 60 * IP(szPrg / 60));
  IF ehX == 40 THEN RECT_P(G0, 40, 145, 282, 148, szLORN, szLORN); END;
  RECT_P(G0, ehX, 145, ehX + 2, 148, szORNG, szORNG);
  IF GETKEY == 4 THEN szStop := 1; END;
  RETURN szStop;
END;

// The Bayesian condition at n, all n positive: kind 1 = this N
// (beta-binomial), kind 2 = N growing (incomplete beta).  1 = met.
sz_BayOK(okK, okPop, okN, okP, okA, okB, okC)
BEGIN
  IF okK == 1 THEN RETURN sz_Ge(sz_BayP(okPop, okN, okN, okP, okA, okB), okC); END;
  RETURN sz_Ge(sz_BayL(okN, okN, okP, okA, okB), okC);
END;

// Least n, all positive, for P(claim | data) >= c.  The condition is
// monotone in n (more positives seen, fewer left to find; checked on the
// verify grid and on the second review's 1,500 random priors), so this is
// a bisection: from the large-N guess ln(1 - c)/ln(p0) - a the step doubles
// outwards (1, 2, 4, ...) until the answer is bracketed, then halves.
// Near the guess that is 3 or 4 sums; at worst about 2 log2(top) (beta 1
// stepped one n at a time: thousands of sums for a strong prior; second
// review, item 1).  top = Kr for a finite N (at n = Kr the claim is
// certain), 1,000,000 as N grows (-1 if even that is not enough).
// Esc between sums: -2.
sz_BaySrch(bsK, bsPop, bsC, bsP, bsA, bsB)
BEGIN
  LOCAL bsTop, bsG, bsLo, bsHi, bsS, bsM;
  bsTop := 1000000;
  IF bsK == 1 THEN bsTop := MIN(bsPop, sz_KrOf(bsPop, bsP)); END;
  bsG := MIN(MAX(CEILING(LN(1 - bsC) / LN(bsP) - bsA), 0), bsTop);
  IF sz_EscHit() == 1 THEN RETURN -2; END;
  IF sz_BayOK(bsK, bsPop, bsG, bsP, bsA, bsB, bsC) == 1 THEN
    // met at the guess: double the step downwards until it fails
    bsHi := bsG; bsLo := -1; bsS := 1;
    WHILE bsLo < 0 DO
      IF bsHi == 0 THEN RETURN 0; END;
      IF sz_EscHit() == 1 THEN RETURN -2; END;
      bsM := MAX(0, bsG - bsS);
      IF sz_BayOK(bsK, bsPop, bsM, bsP, bsA, bsB, bsC) == 1 THEN
        bsHi := bsM; bsS := bsS * 2;
      ELSE
        bsLo := bsM;
      END;
    END;
  ELSE
    // not met: double the step upwards until it is (top always is,
    // for a finite N)
    bsLo := bsG; bsHi := -1; bsS := 1;
    WHILE bsHi < 0 DO
      IF bsLo >= bsTop THEN RETURN -1; END;
      IF sz_EscHit() == 1 THEN RETURN -2; END;
      bsM := MIN(bsTop, bsG + bsS);
      IF sz_BayOK(bsK, bsPop, bsM, bsP, bsA, bsB, bsC) == 1 THEN
        bsHi := bsM;
      ELSE
        bsLo := bsM; bsS := bsS * 2;
      END;
    END;
  END;
  // not met at bsLo, met at bsHi: halve the gap
  WHILE bsHi - bsLo > 1 DO
    IF sz_EscHit() == 1 THEN RETURN -2; END;
    bsM := FLOOR((bsLo + bsHi) / 2);
    IF sz_BayOK(bsK, bsPop, bsM, bsP, bsA, bsB, bsC) == 1 THEN bsHi := bsM; ELSE bsLo := bsM; END;
  END;
  RETURN bsHi;
END;

// Least n, all positive, for P(claim | data) >= c, this N.
sz_BayMin(byPop, byC, byP, byA, byB)
BEGIN
  RETURN sz_BaySrch(1, byPop, byC, byP, byA, byB);
END;

// The same as N grows (P(theta >= p0) >= c), up to 1,000,000.
sz_BayMinL(bzC, bzP, bzA, bzB)
BEGIN
  RETURN sz_BaySrch(2, 1, bzC, bzP, bzA, bzB);
END;

// P(X >= x | K0) and the lower bound for the result in hand (szNt
// tested, szJ negative), and their Home exports.
sz_ObsUpd()
BEGIN
  LOCAL ouX;
  ouX := szNt - szJ;
  szOP := sz_HypS(szN, szK0, szNt, ouX, szNt);
  szOLB := sz_LowB(szN, szNt, ouX, szC);
  SZ_P := szOP;
  SZ_LB := szOLB / szN;
END;

// The tested count: whole, 1..N; the negatives stay <= n.
sz_SetN(snV)
BEGIN
  szNt := MIN(MAX(ROUND(snV, 0), 1), szN);
  szJ := MIN(szJ, szNt);
  sz_ObsUpd();
  szInfo := "";
END;

// The negatives found: whole, 0..n.
sz_SetJ(sjV)
BEGIN
  szJ := MIN(MAX(ROUND(sjV, 0), 0), szNt);
  sz_ObsUpd();
  szInfo := "";
END;

// The least n for dnD negatives (from the list when 0, 1 or 2).
sz_HmOf(dnD)
BEGIN
  IF dnD <= 2 THEN RETURN szHm(dnD + 1); END;
  IF dnD == szD THEN RETURN szHmD; END;
  RETURN sz_HypMin(szN, szC, szP0, dnD);
END;

// Everything that depends on the set-up.  The result in hand becomes the
// hypergeometric plan: least n for szD negatives, szD of them negative.
sz_Recalc()
BEGIN
  LOCAL rcI;
  sz_Busy("Computing ...");
  szStop := 0;
  szKr := sz_KrOf(szN, szP0); szK0 := szKr - 1;
  szHm := {-1, -1, -1}; szBm := {-1, -1, -1};
  FOR rcI FROM 1 TO 3 DO
    szHm(rcI) := sz_HypMin(szN, szC, szP0, rcI - 1);
    szBm(rcI) := sz_BinMin(szC, szP0, rcI - 1);
  END;
  IF szD <= 2 THEN
    szHmD := szHm(szD + 1); szBmD := szBm(szD + 1);
  ELSE
    szHmD := sz_HypMin(szN, szC, szP0, szD); szBmD := sz_BinMin(szC, szP0, szD);
  END;
  szYm := sz_BayMin(szN, szC, szP0, szA, szB);
  szYmL := sz_BayMinL(szC, szP0, szA, szB);
  IF szHmD > 0 THEN
    szNt := szHmD; szJ := szD;
  ELSE
    szJ := 0;
    IF szHm(1) > 0 THEN szNt := szHm(1); ELSE szNt := MIN(szN, 10); END;
  END;
  szBnKey := ""; szBaKey := ""; szOcN := -1; szInfo := "";
  sz_ObsUpd();
  SZ_N := szN; SZ_NMIN := szHm(1);
END;

// The set-up form.  Every field is checked; a value outside its range
// is refused (or pulled in) with a message that says why.
sz_Setup()
BEGIN
  LOCAL suN, suC, suP, suD, suPa, suPb;
  LOCAL suOK, suLp, suMsg;
  suN := szN; suC := szC; suP := szP0; suD := szD; suPa := szA; suPb := szB;
  suLp := szPZ + ":";
  suOK := INPUT({suN, suC, suP, suD, suPa, suPb}, "Seizure and claim",
    {"N units:", "Confidence c:", suLp, "Negatives:", "Prior a:", "Prior b:"},
    {"Units seized, a whole number 1 to 10000", "c strictly between 0 and 1, e.g. 0.95",
     "Claim: at least this proportion contain drug", "Negatives allowed in the sample, 0 to 20",
     "Beta prior: 1 = uniform, 0.5 = Jeffreys", "Beta prior: 1 = uniform, 0.5 = Jeffreys"});
  IF suOK == 0 THEN RETURN 0; END;
  suMsg := "";
  suN := ROUND(suN, 0);
  IF suN < 1 OR suN > 10000 THEN
    MSGBOX("N must be a whole number from 1 to 10000.  Nothing was changed.");
    RETURN 0;
  END;
  IF suC <= 0 OR suC >= 1 THEN
    MSGBOX("c must be strictly between 0 and 1 (0.95 is usual).  Nothing was changed.");
    RETURN 0;
  END;
  IF suP <= 0 OR suP >= 1 THEN
    MSGBOX(szPZ + " must be strictly between 0 and 1 (0.90 is usual).  Nothing was changed.");
    RETURN 0;
  END;
  IF suPa <= 0 OR suPb <= 0 THEN
    MSGBOX("The prior's a and b must be positive (1 and 1 = uniform).  Nothing was changed.");
    RETURN 0;
  END;
  IF suC < 0.5 THEN suC := 0.5; suMsg := suMsg + "c raised to 0.5.  "; END;
  IF suC > 0.9999 THEN suC := 0.9999; suMsg := suMsg + "c lowered to 0.9999.  "; END;
  IF suP < 0.001 THEN suP := 0.001; suMsg := suMsg + szPZ + " raised to 0.001.  "; END;
  IF suP > 0.999 THEN suP := 0.999; suMsg := suMsg + szPZ + " lowered to 0.999.  "; END;
  // beta 1a (second review, item 10): every change is said
  IF ROUND(suD, 0) < 0 OR ROUND(suD, 0) > 20 THEN
    suD := MIN(MAX(ROUND(suD, 0), 0), 20);
    suMsg := suMsg + "Negatives set to " + sz_I(suD) + " (0 to 20).  ";
  END;
  suD := ROUND(suD, 0);
  IF suPa < 0.1 OR suPa > 100 OR suPb < 0.1 OR suPb > 100 THEN
    suPa := MIN(MAX(suPa, 0.1), 100); suPb := MIN(MAX(suPb, 0.1), 100);
    suMsg := suMsg + "Prior a, b kept in 0.1 to 100.  ";
  END;
  // two decimals are enough for a prior, and keep the titles short
  IF ROUND(suPa, 2) <> suPa OR ROUND(suPb, 2) <> suPb THEN
    suPa := ROUND(suPa, 2); suPb := ROUND(suPb, 2);
    suMsg := suMsg + "Prior a, b rounded to 2 decimals.  ";
  END;
  IF DIM(suMsg) > 0 THEN MSGBOX(suMsg); END;
  szN := suN; szC := suC; szP0 := suP; szD := suD; szA := suPa; szB := suPb;
  sz_Recalc();
  RETURN 1;
END;

// What was tested and found.
sz_Observed()
BEGIN
  LOCAL obN, obX, obOK;
  obN := szNt; obX := szNt - szJ;
  obOK := INPUT({obN, obX}, "Tested and found",
    {"n tested:", "x positive:"},
    {"Units analysed, 1 to N = " + sz_I(szN), "Of those, how many held the drug, 0 to n"});
  IF obOK == 0 THEN RETURN 0; END;
  obN := ROUND(obN, 0); obX := ROUND(obX, 0);
  IF obN < 1 OR obN > szN THEN
    MSGBOX("n must be a whole number from 1 to N = " + sz_I(szN) + ".");
    RETURN 0;
  END;
  IF obX < 0 OR obX > obN THEN
    MSGBOX("x must be a whole number from 0 to n = " + sz_I(obN) + ".");
    RETURN 0;
  END;
  szNt := obN; szJ := obN - obX; szInfo := "";
  sz_ObsUpd();
  RETURN 1;
END;

BEGIN

  sz_Frame("Hypergeometric: claim K " + szGE + " " + sz_I(szKr) + " of " + sz_I(szN));
  TEXTOUT_P(szPZ + " = " + sz_G(szP0, 2) + " (K " + szGE + " " + szPZ + "N), c = " + sz_G(szC, 2) + ", " + szKZ + " = " + sz_I(szK0), G1, 6, 20, 1, #000000h, 308);

  TEXTOUT_P("If K = " + szKZ + " = " + sz_I(szK0) + ": P(X " + szGE + " " + sz_I(hdX) + ") " + sz_PStr(szOP), G1, 6, 56, 1, szMAG, 308);
  IF sz_Le(szOP, 1 - szC) == 1 THEN
    TEXTOUT_P(szLE + " 1 - c = " + sz_G(1 - szC, 2) + ": the claim is SUPPORTED", G1, 6, 68, 1, szGRN, 308);
  ELSE
    TEXTOUT_P("> 1 - c = " + sz_G(1 - szC, 2) + ": the claim is NOT supported", G1, 6, 68, 1, szRED, 308);
  END;
  hdS := " K " + szGE + " " + sz_I(szOLB) + " (" + sz_F(szOLB / szN * 100, 1) + "%)";

  hdK2 := szNt;

  END;
  hdFst := MIN(hdFst, hdX);
  IF hdFst > hdK1 THEN
    hdL := sz_HypL(szN, szK0, szNt, MAX(hdFst, hdK1), hdK2);
    hdK1 := MAX(hdFst, hdK1);
  END;
  hdNb := hdK2 - hdK1 + 1;

  szHyK1 := hdK1; szHyNb := hdNb; szHyBw := hdBw; szHyL := hdL;
  IF hdMx <= 0 THEN
    TEXTOUT_P("Every bar in view is 0 (X can be at most " + szKZ + ")", G1, 36, 130, 1, szRED, 270);
  ELSE

      END;
    END;
  END;
  LINE_P(G1, szPL, szPT, szPL, szPB, #000000h);
  LINE_P(G1, szPL, szPB, szPR, szPB, #000000h);
  TEXTOUT_P("P(X = k) if K = " + szKZ + ";  magenta = P(X " + szGE + " x)", G1, szPL + 4, szPT + 1, 1, szGRAY, 270);

// A tap on the bars: which k, and its probabilities.
sz_HypTap(htX, htY)
BEGIN
  LOCAL htI, htK;
  IF htY < szPT OR htY > szPB + 12 OR htX < szPL OR htX > szPR THEN RETURN; END;
  htI := IP((htX - szPL - 1) / szHyBw) + 1;
  IF htI < 1 OR htI > szHyNb THEN RETURN; END;
  htK := szHyK1 + htI - 1;
  szInfo := "k = " + sz_I(htK) + ": P(X = k) " + sz_PStr(szHyL(htI)) + ", P(X " + szGE + " k) " + sz_PStr(sz_HypS(szN, szK0, szNt, htK, szNt));
END;

// "Min n": the least n for the negatives now shown.

  END;
END;

// The prior's name.
sz_PrName()
BEGIN
  IF szA == 1 AND szB == 1 THEN RETURN "uniform"; END;
  IF szA == 0.5 AND szB == 0.5 THEN RETURN "Jeffreys"; END;
  RETURN "typed";
END;

// Both densities per pixel column, and the probabilities, once per
// (prior, n, x) -- cached by a key.
sz_BayFit()
BEGIN
  LOCAL bfKey, bfI, bfW, bfTh, bfAl, bfBe;
  LOCAL bfLb0, bfLb1, bfMx;
  bfKey := sz_G(szA, 0) + "," + sz_G(szB, 0) + "," + sz_I(szNt) + "," + sz_I(szJ) + "," + sz_I(szN) + "," + sz_G(szP0, 2);
  IF bfKey == szBaKey THEN RETURN; END;
  IF szN - szNt > 2000 THEN sz_Busy("Computing ..."); END;
  bfW := szPR - szPL;
  bfAl := szA + szNt - szJ; bfBe := szB + szJ;
  bfLb0 := sz_LnB(szA, szB); bfLb1 := sz_LnB(bfAl, bfBe);
  szBaPr := MAKELIST(0, bfI, 1, bfW);
  szBaPo := MAKELIST(0, bfI, 1, bfW);
  bfMx := 1;
  FOR bfI FROM 1 TO bfW DO
    bfTh := (bfI - 0.5) / bfW;
    szBaPr(bfI) := EXP((szA - 1) * LN(bfTh) + (szB - 1) * LN(1 - bfTh) - bfLb0);
    szBaPo(bfI) := EXP((bfAl - 1) * LN(bfTh) + (bfBe - 1) * LN(1 - bfTh) - bfLb1);
    // the y-top: the tallest value, leaving out the last 2% at an end
    // where a density runs off to infinity (its parameter there below 1)
    IF (bfTh >= 0.02 OR szA >= 1) AND (bfTh <= 0.98 OR szB >= 1) THEN
      IF szBaPr(bfI) > bfMx THEN bfMx := szBaPr(bfI); END;
    END;
    IF (bfTh >= 0.02 OR bfAl >= 1) AND (bfTh <= 0.98 OR bfBe >= 1) THEN
      IF szBaPo(bfI) > bfMx THEN bfMx := szBaPo(bfI); END;
    END;
  END;
  szBaY := bfMx * 1.1;
  szBaP := sz_BayP(szN, szNt, szNt - szJ, szP0, szA, szB);
  szBaL := sz_BayL(szNt, szNt - szJ, szP0, szA, szB);
  SZ_PB := szBaP;
  szBaKey := bfKey;
END;

// ------------------------------------------------------------
// PAGE 4: THE OC CURVE
// The plan "test n, support the claim if at most d are negative".  Its
// probability of supporting the claim, OC = P(X >= n - d | N, n, K), is
// drawn against the TRUE proportion K/N (magenta; blue = binomial).
// Under the curve: red where the claim is false (K <= K0) -- the chance
// of supporting a false claim -- green where it is true.  Drag the red
// knob along the top to change n; drag in the plot to move the true
// proportion (the red line) and read the curve.
// ------------------------------------------------------------

// The OC page's x axis runs from szOcL to 1: 0 to 1 (the whole curve), or
// zoomed to the last 0.2 to 0.3 below p0 and above it, where the curve
// rises.  Column i (1..W) sits at theta = L + (i - 0.5)/W (1 - L).
sz_OCTh(otI, otW)
BEGIN
  RETURN szOcL + (otI - 0.5) / otW * (1 - szOcL);
END;

// Per pixel column: K = floor(theta N) and ln Gamma(K + 1), once per N
// and zoom.  floor puts every theta below Kr/N on a false K: theta N < Kr
// gives K <= Kr - 1 = K0.
sz_OCFit()
BEGIN
  LOCAL ofI, ofW, ofK, ofLast, ofV;
  ofW := szPR - szPL;
  szOcK := MAKELIST(0, ofI, 1, ofW);
  szOcS := MAKELIST(0, ofI, 1, ofW);
  ofLast := -1; ofV := 0;
  FOR ofI FROM 1 TO ofW DO
    // + 1E-9: theta N can land a hair below a whole number in binary
    // (774.9999999999999 for 775 at N = 1000, zoomed; second review);
    // the Prime's decimals do not need it, and it moves nothing else
    ofK := FLOOR(sz_OCTh(ofI, ofW) * szN + 0.000000001);
    szOcK(ofI) := ofK;
    IF ofK <> ofLast THEN ofV := sz_LnG(ofK + 1); ofLast := ofK; END;
    szOcS(ofI) := ofV;
  END;
  szOcN := szN; szOcLf := szOcL;
END;

// Both OC curves for n = szNt, d = szD, at every ocStp-th column (4 while
// a finger drags n, 1 otherwise); the skipped columns hold -1.  While a
// finger drags (ocStp > 1) the binomial curve is left out (all -1).
//   Hypergeometric, K >= n:  P(X = n) = exp(lnG(K+1) - lnG(K-n+1)
//     - lnG(N+1) + lnG(N-n+1)), then P(X = n - j) from P(X = n - j + 1)
//     times (n - j + 1)(N - K - j + 1) / ((K - n + j) j), j = 1..d;
//   K < n: sz_HypS.  Binomial: t^n, then times (n - j + 1)/j (1 - t)/t.
//   A first term below e^-700 makes the sum below 1E-140 (d <= 20): 0.
sz_OCCurve(ocStp)
BEGIN
  LOCAL ocI, ocW, ocK, ocCN, ocLh, ocT;
  LOCAL ocS, ocJ, ocTh, ocQ, ocB, ocPk;
  LOCAL ocPv, ocNn, ocD;
  ocW := szPR - szPL; ocNn := szNt; ocD := szD;
  szOcH := MAKELIST(-1, ocI, 1, ocW);
  szOcB := MAKELIST(-1, ocI, 1, ocW);
  ocCN := sz_LnG(szN + 1) - sz_LnG(szN - ocNn + 1);
  ocPk := -1; ocPv := 0;
  ocI := 1;
  WHILE ocI <= ocW DO
    ocK := szOcK(ocI);
    IF ocK == ocPk THEN
      ocS := ocPv;
    ELSE
      IF ocK >= ocNn THEN
        ocLh := szOcS(ocI) - sz_LnG(ocK - ocNn + 1) - ocCN;
        ocS := 0;
        IF ocLh > -700 THEN
          ocT := EXP(ocLh); ocS := ocT;
          FOR ocJ FROM 1 TO ocD DO
            ocT := ocT * (ocNn - ocJ + 1) * MAX(0, szN - ocK - ocJ + 1) / ((ocK - ocNn + ocJ) * ocJ);
            ocS := ocS + ocT;
          END;
        END;
      ELSE
        ocS := sz_HypS(szN, ocK, ocNn, ocNn - ocD, ocNn);
      END;
      ocPk := ocK; ocPv := ocS;
    END;
    szOcH(ocI) := MIN(ocS, 1);
    IF ocStp == 1 THEN
      ocTh := sz_OCTh(ocI, ocW); ocQ := 1 - ocTh;
      ocLh := ocNn * LN(ocTh);
      ocB := 0;
      IF ocLh > -700 THEN
        ocT := EXP(ocLh); ocB := ocT;
        FOR ocJ FROM 1 TO MIN(ocD, ocNn) DO
          ocT := ocT * (ocNn - ocJ + 1) / ocJ * ocQ / ocTh;
          ocB := ocB + ocT;
        END;
      END;
      szOcB(ocI) := MIN(ocB, 1);
    END;
    IF ocI < ocW AND ocI + ocStp > ocW THEN ocI := ocW; ELSE ocI := ocI + ocStp; END;
  END;
END;

// One step of a finger drag: 1 while the finger is still down on the
// screen (its x in szDgX), 0 when it lifted, when any key is pressed, or
// when the reading is off the screen (a stuck or phantom touch; PrimeSUD
// once read (2147483647, 0)).  A key that ended the drag is drained.
sz_DragOn()
BEGIN
  LOCAL dkK, dkM, dkM1;
  dkK := GETKEY;
  IF dkK > -1 THEN
    REPEAT dkK := GETKEY; UNTIL dkK == -1;
    RETURN 0;
  END;
  dkM := MOUSE;
  dkM1 := dkM(1);
  IF SIZE(dkM1) < 2 THEN RETURN 0; END;
  IF dkM1(1) < 0 OR dkM1(1) > 319 OR dkM1(2) < 0 OR dkM1(2) > 239 THEN RETURN 0; END;
  szDgX := dkM1(1) + 0.0;
  RETURN 1;
END;

sz_OCPage()
BEGIN

  LOCAL ocY, ocNw, ocDg;
  szPL := 30; szPR := 312; szPT := 44; szPB := 164;
  IF szOcN <> szN OR szOcLf <> szOcL THEN
    sz_Busy("Computing ...");
    sz_OCFit();
  END;
  sz_OCTop();
  sz_OCCurve(1);
  szOcT := MIN(MAX(ROUND(szP0 - 0.1, 2), MAX(0.01, szOcL)), 0.99);
  ocGo := 1;
  REPEAT ocK := GETKEY; UNTIL ocK == -1;
  sz_Drain();
  WHILE ocGo == 1 DO
    sz_OCDraw(0);
    REPEAT
      ocK := GETKEY;
      ocM := MOUSE;
      ocM1 := ocM(1);
    UNTIL ocK > -1 OR SIZE(ocM1) > 0;
    IF SIZE(ocM1) > 0 THEN
      ocX := ocM1(1) + 0.0; ocY := ocM1(2) + 0.0;
      IF ocY >= 218 THEN
        sz_Drain();
        ocSl := MIN(6, IP(ocX / 53.4) + 1);
        IF ocSl == 1 THEN sz_OCSetN(szNt - 1); END;
        IF ocSl == 2 THEN sz_OCSetN(szNt + 1); END;
        IF ocSl == 3 THEN sz_OCSetD(szD - 1); END;
        IF ocSl == 4 THEN sz_OCSetD(szD + 1); END;
        IF ocSl == 5 THEN sz_OCZoom(); END;
        IF ocSl == 6 THEN ocGo := sz_OCMenu(); END;
      ELSE
        IF ocY < 40 THEN
          // ---- drag the n knob: every fourth column while the finger
          // is down, every column when it lifts.  beta 1a (second review,
          // item 5; ScatterLab's slDragPt guards): any key ends the drag,
          // and so does a reading off the screen (a stuck or phantom
          // touch, Lessons Learned 7); a frame is drawn only when n
          // changes ----
          ocDg := 1;
          WHILE ocDg == 1 DO
            ocNw := 1 + ROUND((MIN(MAX(ocX, 30), 300) - 30) / 270 * (szOcM - 1), 0);
            IF ocNw <> szNt THEN
              szNt := MIN(MAX(ocNw, 1), szN);
              szJ := MIN(szJ, szNt);
              sz_OCCurve(4);
              sz_OCDraw(1);
            END;
            ocDg := sz_DragOn();
            IF ocDg == 1 THEN ocX := szDgX; END;
          END;
          sz_Drain();
          sz_OCSetN(szNt);
        ELSE
          IF ocY >= szPT AND ocY <= szPB + 12 AND ocX >= szPL AND ocX <= szPR THEN
            // ---- drag the true proportion: nothing is recomputed; the
            // same guards as the knob, and a frame only when theta moves ----
            ocDg := 1; ocNw := -1;
            WHILE ocDg == 1 DO
              szOcT := szOcL + MIN(MAX((ocX - szPL) / (szPR - szPL), 0), 1) * (1 - szOcL);
              IF szOcT <> ocNw THEN sz_OCDraw(0); ocNw := szOcT; END;
              ocDg := sz_DragOn();
              IF ocDg == 1 THEN ocX := szDgX; END;
            END;
          END;
          sz_Drain();
        END;
      END;
    ELSE
      IF ocK == 45 THEN sz_OCSetN(szNt - 1); END;
      IF ocK == 50 THEN sz_OCSetN(szNt + 1); END;
      IF ocK == 7 THEN szOcT := MAX(szOcL, ROUND(szOcT - 0.01, 2)); END;
      IF ocK == 8 THEN szOcT := MIN(1, ROUND(szOcT + 0.01, 2)); END;
      IF ocK == 2 THEN sz_OCSetD(szD + 1); END;
      IF ocK == 12 THEN sz_OCSetD(szD - 1); END;
      IF ocK == 30 THEN ocGo := sz_OCMenu(); END;
      IF ocK == 4 THEN ocGo := 0; END;
      REPEAT ocK := GETKEY; UNTIL ocK == -1;
    END;
  END;
  szInfo := "";
END;

// PAGE 5: THE TOTAL NET WEIGHT
// Dot plot of the weights (blue) with their mean (green); below, the
// total: the two-sided CI (orange bar), the estimate (green) and the
// one-sided lower bound (red, with an arrow to the right).

// Mean and SD (n - 1 divisor) of the weights, two passes.
sz_WtStats()
BEGIN
  LOCAL wsI, wsS, wsQ;
  szWn := SIZE(szWt);
  wsS := 0;
  FOR wsI FROM 1 TO szWn DO wsS := wsS + szWt(wsI); END;
  szWm := wsS / szWn;
  wsQ := 0;
  FOR wsI FROM 1 TO szWn DO wsQ := wsQ + (szWt(wsI) - szWm)^2; END;
  szWs := (wsQ / (szWn - 1))^0.5;
END;

// Total, SE, t values, the interval and the lower bound.
//   T = N w-bar; SE = N s/sqrt(n) sqrt((N - n)/N)  (beta 1a: was
//   (N - n)/(N - 1); second review, item 2; Cochran, and ENFSI 2009 s7);
//   t2 = t(n - 1) upper (1 - c)/2 point, t1 = upper 1 - c point, both as
//   -STUDENT_ICDF of a lower tail (Lessons Learned 3).
sz_WtCalc()
BEGIN
  LOCAL wcT, wcF, wcSE, wcT2, wcT1;
  wcT := szN * szWm;
  wcF := 0;
  wcF := MAX(0, (szN - szWn) / szN)^0.5;
  wcSE := szN * szWs / szWn^0.5 * wcF;
  wcT2 := -STUDENT_ICDF(szWn - 1, (1 - szC) / 2);
  wcT1 := -STUDENT_ICDF(szWn - 1, 1 - szC);
  szWr := {wcT, wcSE, wcT2, wcT - wcT2 * wcSE, wcT + wcT2 * wcSE, wcT1, wcT - wcT1 * wcSE, wcF};
  SZ_TOT := wcT;
  SZ_TLB := wcT - wcT1 * wcSE;
END;

// Load the weights: 1 = list D1, 2 = a typed summary, 3 = the example.
sz_WtLoad(wlSrc)
BEGIN
  LOCAL wlN, wlL, wlI, wlOK, wlM, wlS;
  LOCAL wlEx, wlMin;
  IF wlSrc == 1 THEN
    IFERR wlN := SIZE(D1); THEN wlN := 0; END;
    IF wlN < 2 THEN
      MSGBOX("Put the net weights (g) of the units you tested in list D1 of the Statistics 1Var app first: at least two values.");
      RETURN 0;
    END;
    wlL := D1;
    wlMin := sz_LMin(wlL);
    IF wlMin <= 0 THEN
      MSGBOX("Every weight in D1 must be positive.");
      RETURN 0;
    END;
    IF wlN > szN THEN
      MSGBOX("D1 holds " + sz_I(wlN) + " weights but N = " + sz_I(szN) + ": raise N in Set up.");
      RETURN 0;
    END;
    szWt := wlL; sz_WtStats(); szWsrc := "list D1";
  END;
  IF wlSrc == 2 THEN
    wlN := MAX(2, MIN(10, szN)); wlM := 0.5; wlS := 0.02;
    IF szWok == 1 THEN wlN := szWn; wlM := szWm; wlS := szWs; END;
    wlOK := INPUT({wlN, wlM, wlS}, "Weights of the tested units",
      {"n weighed:", szXB + " (g):", "s (g):"},
      {"How many units were weighed, 2 to N", "Their mean net weight, in grams", "Their SD (divisor n - 1), in grams"});
    IF wlOK == 0 THEN RETURN 0; END;
    wlN := ROUND(wlN, 0);
    IF wlN < 2 OR wlN > szN THEN
      MSGBOX("n must be a whole number from 2 to N = " + sz_I(szN) + ".");
      RETURN 0;
    END;
    IF wlM <= 0 OR wlS < 0 THEN
      MSGBOX("The mean must be positive and the SD not negative.");
      RETURN 0;
    END;
    szWt := {}; szWn := wlN; szWm := wlM; szWs := wlS; szWsrc := "typed summary";
  END;
  IF wlSrc == 3 THEN
    IF szN < 2 THEN
      MSGBOX("N must be at least 2 for the example.");
      RETURN 0;
    END;
    // ten made-up net weights in grams (illustrative numbers)
    wlEx := {0.512, 0.498, 0.505, 0.521, 0.487, 0.509, 0.515, 0.493, 0.502, 0.511};
    wlN := MIN(10, szN);
    wlL := MAKELIST(0, wlI, 1, wlN);
    FOR wlI FROM 1 TO wlN DO wlL(wlI) := wlEx(wlI); END;
    szWt := wlL; sz_WtStats(); szWsrc := "illustrative numbers";
  END;
  szWok := 1;
  sz_WtCalc();
  szInfo := "";
  RETURN 1;
END;

// A tap on the weight page: a dot's weight, or what the bars mean.
sz_WtTap(wtX, wtY)
BEGIN
  LOCAL wtI, wtB, wtD, wtLo, wtHi, wtS;
  LOCAL wtPx;
  IF wtY >= 92 AND wtY <= 132 AND SIZE(szWt) >= 2 THEN
    wtLo := sz_LMin(szWt); wtHi := MAX(szWt);
    IF wtHi - wtLo <= 0 THEN wtLo := wtLo * 0.99; wtHi := wtHi * 1.01; END;
    wtS := sz_Nice((wtHi - wtLo) / 4);
    wtLo := FLOOR(wtLo / wtS) * wtS; wtHi := CEILING(wtHi / wtS) * wtS;
    IF wtHi <= wtLo THEN wtHi := wtLo + wtS; END;
    wtB := 0; wtD := 9999;
    FOR wtI FROM 1 TO SIZE(szWt) DO
      wtPx := 30 + IP((szWt(wtI) - wtLo) / (wtHi - wtLo) * 270 + 0.5);
      IF ABS(wtPx - wtX) < wtD THEN wtD := ABS(wtPx - wtX); wtB := wtI; END;
    END;
    IF wtB > 0 THEN
      szInfo := "unit " + sz_I(wtB) + ": " + sz_W(szWt(wtB)) + " g (mean " + sz_W(szWm) + " g)";
    END;
  END;
  IF wtY >= 140 AND wtY <= 182 THEN
    szInfo := "t = " + sz_F(szWr(3), 3) + " (CI), " + sz_F(szWr(6), 3) + " (bound); FPC = " + sz_F(szWr(8), 4);
  END;
END;

    IF mnI == 3 THEN sz_BinPage(); END;
    IF mnI == 4 THEN sz_BayPage(); END;
    IF mnI == 5 THEN sz_OCPage(); END;
    IF mnI == 6 THEN sz_WtPage(); END;
    IF mnI == 7 THEN sz_TabPage(); END;
    IF mnI == 8 THEN
      IF sz_Observed() == 1 THEN sz_HypPage(); END;
    END;
    IF mnI == 9 THEN sz_Help(); END;
  END;
  mnS := "SeizureLab: N = " + sz_I(szN) + ", " + szPZ + " = " + sz_G(szP0, 2) + ", c = " + sz_G(szC, 2);
  mnS := mnS + ": test " + sz_NStr(szHm(1)) + " (all positive; Bayes " + sz_NStr(szYm) + ")";

END;
