# Documentation

| File | What it is |
| --- | --- |
| `lessons-learned_v7c.md` | The main reference: PPL and MicroPython behaviour found on hardware. Start here. |
| `micropython-on-the-prime.md` | Field notes on the Python side — what the interpreter is, how the bridge fails, when it is worth using. |
| `implementation-notes.md` | Why the code looks the way it does. Annotated excerpts, for people who write PPL. |
| `normexplorer-guide.md` | User's guide to NormExplorer, written for students. |
| `studrange-guide.md` | User's guide to StudRange and StudRangePy. |
| `chitable-guide.md` | User's guide to ChiTable, the two-way-table chi-square program. |
| `historical-cross-checks.md` | Worked examples from HP's own 1970s statistics programs, used as a second check on NormExplorer and BayesTree, plus reference cases for testing your own programs. |

All seven are free for educational and personal use; see the LICENSE in the
repository root.
