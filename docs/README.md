# Documentation

| File | What it is |
| --- | --- |
| `lessons-learned_v7h.md` | The main reference: PPL, CAS and MicroPython behaviour found on hardware, and the house rules that came out of it. Start here. |
| `micropython-on-the-prime.md` | Field notes on the Python side: what the interpreter is, how the bridge fails, and when it is worth using. |
| `implementation-notes.md` | Why the code looks the way it does. Annotated excerpts, for people who write PPL. |
| `historical-cross-checks.md` | Worked examples from HP's own 1970s statistics programs, used as a second check on NormExplorer and BayesTree, plus reference cases for testing your own programs. |
| `normexplorer-guide.md` | User's guide to NormExplorer (beta 42), written for students. |
| `studrange-guide.md` | User's guide to StudRange (beta 15a, with the MicroPython engine). |
| `chitable-guide.md` | User's guide to ChiTable (beta 3b), the two-way-table chi-square program. |
| `scatterlab-guide.md` | User's guide to ScatterLab (beta 2a). |
| `binorm3d-guide.md` | User's guide to BiNorm3D (beta 1). |
| `cicatcher-guide.md` | User's guide to CICatcher (beta 2a). |
| `errorrate-guide.md` | User's guide to ErrorRate Lab (beta 1a). |
| `changes/` | One file per program version: what changed and why, with line numbers; the lint and verification output; and the device-test checklist, ordered from least to most risky. |
| `dev/` | The fleet review of 16 October 2026 and the CAS-and-MicroPython plan that drove the touch, graphics and CAS versions, kept as a record of how the work was planned; and the emulator report of 17 October 2026 (`emulator-round1-2026-10-17.md`). |

The guides say "not yet run on hardware" in their firmware line until a calculator has run that version, and they name any run on the HP Prime Virtual Calculator.

All of it is free for educational and personal use; see the LICENSE in the repository root.
