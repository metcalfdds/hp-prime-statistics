Adding a data file you made with the Data Loader?

Click Add a data file you were given, a little further down, and choose your file (it is in your Downloads folder, and its name is like M1.hpmat). Then click the button in step 3. Your data and the DataLoad program are added; everything else on the calculator stays.

More choices: single programs, and data

A data set is a table of numbers from a real study. You only need one if the book or your instructor tells you to use it. It goes into the calculator's matrix M1; the program DataLoad then moves it into the calculator's statistics lists. DataLoad is added for you whenever you load data.

Use this only if your instructor gave you a data file, or you made one with the Data Loader. Its name must be M0.hpmat to M9.hpmat.

You're using Firefox: that's fine, it just takes a few more clicks

Why it's different: Firefox never lets a web page put files into a folder on your computer. That is a safety choice its makers made on purpose, so nothing on this page can change it. Instead, the page gives you one file to download, and Windows itself unpacks it into the calculator's folder. It takes about two minutes.

If you would rather have the page do the copying, open it in Microsoft Edge instead, which every Windows computer has. "Something not working?" at the bottom of the page says how.

3Load

If the Virtual Calculator is open, close it first. Then click the button.

The first time you click Load, the browser asks two things:

  1. A window opens showing your Documents folder. Click the folder HP Prime once, then click Select Folder. (Ignore "Upload from mobile".) This tells the page where the calculator keeps its programs.
  2. Your browser asks whether to let this page edit files there. Click Edit files (or Allow). This lets the page work in that one folder and nowhere else.

After that, the page remembers the folder and doesn't ask again.

The Virtual Calculator looks open

Close it: click the small word Calculator at the top left of its window, then Exit (or click the X at the top right of its window). Then click Try again.

Why: when the calculator closes it saves everything it remembers, right over the new programs, and they would be gone.

If you are sure it is closed, click It is closed: load. (The calculator leaves a small marker file while it is open; if it ever crashed, that marker can be left behind.)

Done. Now start the Virtual Calculator.

    What just happened:

      What Load does

      Load checks that the calculator is closed, copies the programs into the calculator's folder, and reads each one back to make sure it arrived whole. It takes a few seconds.

      All the programs, or programs you tick, are added: the programs already on the calculator stay. If one of them has the same name as a program being loaded, it is replaced by this page's copy.

      One chapter leaves the calculator with that chapter's programs: the book's other programs are moved off first. A program of your own is never moved.

      Nothing is ever deleted. Whatever is replaced or moved off is kept in Documents\HP Prime\Loader backups, in a folder named with the date and time. HP's own apps and settings are never touched.

      3Download the programs and unpack them into the calculator

      1. Close the Virtual Calculator if it is open (the small word Calculator at the top left of its window, then Exit).

        The calculator reads its programs only when it starts, and when it closes it saves its old memory right over anything new.

      2. Click this button:

        Your browser saves one file, called HP_Prime_programs.zip, in your Downloads folder. A zip file is a bundle: several files packed into one so they download together.

      3. Open your Downloads folder.

        In Firefox: click the downloads arrow at the top right of the window, then the small folder icon next to the file. Or open File Explorer (the yellow folder on the taskbar) and click Downloads on the left.

      4. Right-click the zip file and choose Extract All…

        "Extract" means unpack. Windows will ask where to put the files: the next step points it at the calculator's folder.

      5. Click Browse…, then open Documents, then HP Prime, then Calculators, then Prime, and click Select Folder.

        The long box above Browse should now end in \HP Prime\Calculators\Prime. That Prime folder is where the calculator keeps its programs. It reads them from there each time it starts.

      6. Click Extract.

        If Windows says files with the same name are already there, choose Replace the files in the destination: the new ones are the up-to-date programs. A window showing the folder may pop up afterwards; you can close it.

      7. Start the Virtual Calculator. Press Shift, then Program (the 1 key). Your programs are listed: …. Tap one, then tap Run. That's all.

        If one ever says Syntax Error, or Run does nothing: tap it, tap Edit, tap Check, tap OK, press Esc, then tap Run. Once is enough.

        CentralLimit is an app rather than a program: press Apps, move to CentralLimit without touching it, and tap Start. Then press View for its menu.

        Your data is in matrix M1: open the Statistics 1Var app once (Apps), then run DataLoad to put the columns into its lists.

      Unpacking adds programs without taking any away: programs already on your calculator stay there, whichever choice you made in step 2.

      3Put them on your HP Prime with HP's Connectivity Kit

      A real HP Prime keeps its programs inside the calculator, so they travel down its USB cable. HP's free Connectivity Kit does the moving.

      Don't have the Kit? hpcalc.org's HP Prime page lists it, with Hewlett-Packard as its author. Download it and install it.

      1. Click this button:

        Your browser saves one file, called HP_Prime_programs.zip, in your Downloads folder.

      2. Unpack it: open your Downloads folder, right-click the zip file, choose Extract All…, then click Extract.

        A window opens showing the program files, each ending in .hpprgm. Leave that window open.

      3. Start the Connectivity Kit. Then plug the calculator into the computer with its USB cable, and turn it on.

        At the top left of the Kit's window, under Calculators, your calculator's name appears.

      4. Drag each program file from the unpacked folder and drop it on the calculator's name.

        Drop it right on the name, not into the Content box below it: Content is only the Kit's own shelf. The calculator takes each program in straight away.

        CentralLimit is an app, not a program, so it is a folder: CentralLimit.hpappdir. Drag the whole folder onto the calculator's name the same way. (This one step has not been tried on a real calculator yet; if the Kit will not take the folder, tell your instructor.)

        Your data file (M1.hpmat) goes on the same way (not yet tried on a real calculator). On the calculator, open the Statistics 1Var app once (Apps), then run DataLoad to put its columns into the lists.

      5. Close the Connectivity Kit, or unplug the calculator.

        While the Kit is open it keeps asking the calculator what it holds, and that slows the calculator down.

      6. On the calculator, press Shift, then Program (the 1 key). Your programs are listed: …. Tap one, then tap Run.

        CentralLimit is an app rather than a program: press Apps, move to CentralLimit without touching it, and tap Start. Then press View for its menu.

      Programs already on your calculator stay there, whichever choice you made in step 2. A real calculator has much less room than a computer; to take a program off, open the Program Catalog, tap its name, tap More, then Delete.

      The Kit does not show my calculator

      Make sure Bonjour is running. The Connectivity Kit uses a small Apple program called Bonjour to find calculators (HP includes Bonjour with the Kit). On some computers Bonjour gets stopped, and then the Kit may not see your calculator at all, or may misbehave. To check it:

      1. Press the Windows key, type Services, and open the Services app.
      2. Find Bonjour Service in the list. The list is in alphabetical order, so it is near the top.
      3. Look at its Status column: it should say Running. If it doesn't, right-click Bonjour Service and choose Start. Windows may ask for an administrator's permission; on a school computer, ask your instructor or the IT help desk.

      Instructors: the hp-prime-statistics repository has a small launcher (tools/windows-launcher) that checks Bonjour, starts it if needed, and then opens the Kit.

      If the mouse pointer shows a circle with a line through it when you drag, the Kit may be set to run as administrator: right-click its shortcut, Properties, Compatibility, and clear "Run this program as an administrator".

      Being tested: straight down the cable, with no Connectivity Kit

      This sends the programs from this page to the calculator through its USB cable, and reads each one back to see that it arrived whole. It has not been proved on a real calculator yet, which is why only this page's test address shows it. Close the Connectivity Kit first, and leave the calculator switched on at its Home screen.

        Something not working?

        I don't have the Virtual Calculator yet

        It is a free program from HP for Windows. hpcalc.org's HP Prime page lists it, with Hewlett-Packard as its author. Download it and install it.

        Then start it once and close it again. Its first start makes a folder in your Documents called HP Prime, which is where it keeps its programs and where this page puts them.

        The page says it can't put files on the calculator, or I want to open it in Edge

        Firefox and Safari don't allow any web page to put files into a folder, so the page shows the download steps instead. Those work fine. To have the page do the copying for you, open it in Microsoft Edge:

        1. If you opened this page from a file on your computer: right-click the file, choose Open with, then Microsoft Edge.
        2. If you opened it from a link: click in the address bar at the top of this window, copy the address (Ctrl+C), open Edge (the blue-green swirl on the taskbar or Start menu), click its address bar, paste (Ctrl+V) and press Enter.
        There's no folder called HP Prime in my Documents

        Start the Virtual Calculator once and close it again: its first start makes the folder. If you still can't find it, your computer may keep Documents in OneDrive: on the left of the window, look under OneDrive → Documents.

        The page says the calculator looks open, but I closed it

        Look at the taskbar at the bottom of the screen: if the calculator's icon is still there, it may be open on another screen or minimized. Close it there. If it really is closed, click It is closed: load.

        A program says "Syntax Error", or Run does nothing

        Press Shift, then Program. Tap the program, tap Edit, tap Check (bottom right). The calculator says "No errors in the program". Tap OK, press Esc, then tap Run. This rebuilds the program for your calculator; you only ever need to do it once per program.

        If you typed the program's name in the calculator's Home screen instead, type it exactly as listed, capitals included (for example TTESTLABG). Tapping it in the program list is easier.

        A program I had is gone, or I want an old one back

        Load never deletes a program. One that it replaced, or that One chapter moved off the Virtual Calculator, is in Documents\HP Prime\Loader backups, in a folder named with the date and time. To get the book's programs back, choose All the programs and click Load. To get back a file from the backup, close the calculator, copy it from there into Documents\HP Prime\Calculators\Prime, and start the calculator.

        Can the Connectivity Kit load the Virtual Calculator too?

        Yes. Choose A real HP Prime in step 1 and follow its steps, with one change: start the Virtual Calculator where the steps say to plug the calculator in. The Kit lists it as Virtual Prime.
