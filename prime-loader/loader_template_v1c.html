HP Prime Loader

This page puts the programs for your chapter of the book onto the HP Prime Virtual Calculator, HP's free calculator program for your computer. You don't need to type anything into the calculator or know how it works inside. Pick your chapter, follow the steps below, and the programs will be waiting for you the next time you start the calculator.

You're using Edge or Chrome: this page can do the copying for you

When you click Load, the page puts the programs straight onto the Virtual Calculator. It asks your permission first, and it can only touch the one folder you choose.

You're using Firefox: that's fine, it just takes a few more clicks

Why it's different: Firefox never lets a web page put files into a folder on your computer. That is a safety choice its makers made on purpose, so nothing on this page can change it. Instead, the page gives you one file to download, and Windows itself unpacks it into the calculator's folder. It takes about two minutes, and you only do it once per chapter.

If you would rather have the page do the copying, open it in Microsoft Edge instead, which every Windows computer has. "Something not working?" at the bottom of the page says how.

Before you start

The HP Prime Virtual Calculator must be installed on this computer, and you must have started it at least once.

Why: the first time the calculator starts, it makes a folder in your Documents called HP Prime, and that is where it keeps its programs. If you have never started it, start it now and then close it again. This page is for Windows; Macs have not been tested yet.

1Pick your chapter

Each card below is one chapter of the book. The names under the chapter's title are the programs that chapter uses. Tap your chapter: it turns blue. Tap it again to unpick it. You can pick more than one chapter, but fewer programs make the calculator easier to find your way around, so pick only what you need right now.

A data set is a table of numbers from a real study. You only need one if the book or your instructor tells you to use it. It goes into the calculator's matrix M1; the program DataLoad then moves it into the calculator's statistics lists.

Use this only if your instructor gave you a data file, or you made one with the Data Loader. Its name must be M0.hpmat to M9.hpmat.

Pick programs one by one instead (for instructors)

2Close the Virtual Calculator

If the calculator is open, close it: click the small word Calculator at the top left of its window, then Exit. Or just click the X at the top right of its window. If it isn't open, go on to step 3.

Why: the calculator reads its programs only when it starts, and when it closes it saves everything it remembers. If it is open while the programs go in, then when you close it later it saves its old memory right over the new programs, and they are gone. Closed first, it picks them up the next time it starts.

3Load

The first time you click Load:

  1. A window opens showing your Documents folder. Click the folder HP Prime once, then click Select Folder. (Ignore "Upload from mobile".) This tells the page where the calculator keeps its programs.
  2. Your browser asks whether to let this page edit files there. Click Edit files (or Allow). This lets the page work in that one folder and nowhere else.

After that, the page remembers the folder and doesn't ask again.

What Load does: it checks that the calculator is closed. It moves any programs already on the calculator into a backup folder (HP Prime\Loader backups), so nothing is lost and your calculator holds only this chapter's programs. Then it copies your chapter's programs on and checks each one. HP's own apps and settings are never touched. It takes a few seconds.

The Virtual Calculator looks open

Close it: click the small word Calculator at the top left of its window, then Exit (or click the X at the top right of its window). Then click Try again.

If you are sure it is closed, click It is closed: load. (The calculator leaves a small marker file while it is open; if it ever crashed, that marker can be left behind.)

Done. Now start the Virtual Calculator.

    What just happened:

      3Download the programs and unpack them into the calculator

      1. Click this button:

        Your browser saves one file, called HP_Prime_programs.zip, in your Downloads folder. A zip file is a bundle: several files packed into one so they download together.

      2. Open your Downloads folder.

        In Firefox: click the downloads arrow at the top right of the window, then the small folder icon next to the file. Or open File Explorer (the yellow folder on the taskbar) and click Downloads on the left.

      3. Right-click the zip file and choose Extract All…

        "Extract" means unpack. Windows will ask where to put the files: the next step points it at the calculator's folder.

      4. Click Browse…, then open Documents, then HP Prime, then Calculators, then Prime, and click Select Folder.

        The long box above Browse should now end in \HP Prime\Calculators\Prime. That Prime folder is where the calculator keeps its programs. It reads them from there each time it starts.

      5. Click Extract.

        If Windows says files with the same name are already there, choose Replace the files in the destination: the new ones are the up-to-date programs. A window showing the folder may pop up afterwards; you can close it.

      6. Start the Virtual Calculator. Press Shift, then Program (the 1 key). Your programs are listed: …. Tap one, then tap Run. That's all.

        If one ever says Syntax Error, or Run does nothing: tap it, tap Edit, tap Check, tap OK, press Esc, then tap Run. Once is enough.

        CentralLimit is an app rather than a program: press Apps, move to CentralLimit without touching it, and tap Start. Then press View for its menu.

        Your data is in matrix M1: open the Statistics 1Var app once (Apps), then run DataLoad to put the columns into its lists.

      Unlike Load in Edge, unpacking adds programs without taking any away: programs already on your calculator stay there.

      Something not working?

      The page says it can't put files on the calculator, or I want to open it in Edge

      Firefox and Safari don't allow any web page to put files into a folder, so the page shows the download steps instead. Those work fine. To have the page do the copying for you, open it in Microsoft Edge:

      1. If you opened this page from a file on your computer: right-click the file, choose Open with, then Microsoft Edge.
      2. If you opened it from a link: click in the address bar at the top of this window, copy the address (Ctrl+C), open Edge (the blue-green swirl on the taskbar or Start menu), click its address bar, paste (Ctrl+V) and press Enter.
      There's no folder called HP Prime in my Documents

      Start the Virtual Calculator once and close it again: its first start makes the folder. If you still can't find it, your computer may keep Documents in OneDrive: on the left of the window, look under OneDrive → Documents.

      The page says the calculator looks open, but I closed it

      Look at the taskbar at the bottom of the screen: if the calculator's icon is still there, it may be open on another screen or minimized. Close it there. If it really is closed, click It is closed: load.

      A program says "Syntax Error", or Run does nothing

      Press Shift, then Program. Tap the program, tap Edit, tap Check (bottom right). The calculator says "No errors in the program". Tap OK, press Esc, then tap Run. This rebuilds the program for your calculator; you only ever need to do it once per program.

      If you typed the program's name in the calculator's Home screen instead, type it exactly as listed, capitals included (for example TTESTLABG). Tapping it in the program list is easier.

      I want back the programs I had before

      Load in Edge moves them to Documents\HP Prime\Loader backups, in a folder named with the date and time. Close the calculator, then copy the ones you want from there into Documents\HP Prime\Calculators\Prime, and start the calculator.

      Another way, with HP's Connectivity Kit (also for a real HP Prime, G1 or G2)

      HP's free Connectivity Kit is the other way to put programs on a calculator. It works the same way for the Virtual Calculator and for a real HP Prime (the older G1 or the newer G2), and for a real Prime it is the only way. Use it if the Kit is already installed on your computer, or if you have a real Prime.

      First, make sure Bonjour is running. The Connectivity Kit uses a small Apple program called Bonjour to find calculators, the Virtual Calculator included (HP includes Bonjour with the Kit). On some computers Bonjour gets stopped, and then the Kit may not see your calculator at all, or may misbehave. To check it:

      1. Press the Windows key, type Services, and open the Services app.
      2. Find Bonjour Service in the list. The list is in alphabetical order, so it is near the top.
      3. Look at its Status column: it should say Running. If it doesn't, right-click Bonjour Service and choose Start. Windows may ask for an administrator's permission; on a school computer, ask your instructor or the IT help desk.

      Instructors: the hp-prime-statistics repository has a small launcher (tools/windows-launcher) that checks Bonjour, starts it if needed, and then opens the Kit.

      1. Pick your chapter above, click the button below to download the files, and unzip them (right-click the zip, Extract All…, Extract).
      2. Start the Connectivity Kit.
      3. Start the Virtual Calculator. Or, for a real Prime (G1 or G2), plug it into the computer with its USB cable and turn it on.
      4. On the left of the Kit's window, under Calculators, you will see Virtual Prime (or your real calculator). Drag each program file from the unzipped folder and drop it right on that name. The calculator takes it in straight away; nothing needs checking.

      Drop the files on the calculator's name, not into the Content box below it: Content is only the Kit's own shelf. If the mouse pointer shows a circle with a line through it, the Kit may be set to run as administrator: right-click its shortcut, Properties, Compatibility, and clear "Run this program as an administrator".
