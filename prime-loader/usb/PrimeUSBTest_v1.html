HP Prime USB test

This page tries something new: putting a program on a real HP Prime through its USB cable, straight from the browser, with no Connectivity Kit, and reading the program back to see that it arrived whole.

It has never been run on a calculator. It was written from other people's published measurements and tried only on a pretend calculator. This test is the first real run, and its log says what works.

The page is for the book's author, or for an instructor with a calculator to spare. It is not for students: they should use the HP Prime Loader.

This browser cannot talk to a USB device

Open this page in Microsoft Edge or Google Chrome on the Windows computer the calculator is plugged into. Firefox and Safari do not let a web page reach a USB device, and neither does a phone.

1Before you start

  1. Back the calculator up first, if it holds anything you would miss. HP's Connectivity Kit can make the backup.

    The test only writes four test programs of its own and deletes them again. But it is a first run, and a calculator that freezes may need its reset hole, which can cost what is in its memory.

  2. Close HP's Connectivity Kit.

    Windows gives a USB device to one program at a time. While the Kit is open, this page cannot reach the calculator.

  3. Turn the calculator on, leave it at its Home screen, and plug it into this computer with its USB cable.

2Connect

The browser opens a small window that lists the calculator. Click its name, then click Connect. The browser asks every time, so that no page can reach a device behind your back.

3Run the test

The test sends a small test program four different ways and reads it back. Each way that works then climbs to bigger programs, up to the size of the book's largest (EpiStats, 289,813 characters). A way stops at its first failure. The whole test takes a few minutes; do not unplug the calculator or press its keys while it runs.

On the calculator it writes four programs at most, named ZZUSBA, ZZUSBB, ZZUSBC and ZZUSBD, and deletes them at the end. It reads, changes and deletes nothing else.

4Send the log

    
The log is what tells us what to build next. It holds what was sent and what came back, in numbers; it does not hold the calculator's serial number or anything from the calculator but the test programs. Save it and attach the file to your chat with Claude, whatever the test found, failures most of all.
